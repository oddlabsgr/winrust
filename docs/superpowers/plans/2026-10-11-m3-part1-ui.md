# M3 Part 1: Main Window UI Crate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `crates/ui` (`winrust-ui`): the main window's layout, hit-testing, pointer interaction, compositor, scrolling title and visualizer, all pure and tested without a window, plus the skin-crate and Winrust Base fixes it needs and a `skin-tool render` command.

**Architecture:**
- **Layout table** (`layout.rs`): every widget's rectangle at 1×, normal and shade mode, copied from Webamp's CSS; `hit_test` returns the topmost widget.
- **Snapshot** (`view.rs`): `MainView` is what the app shows this frame; pure functions format the time, slider frames, thumbs and slider texts.
- **Pointer state machine** (`interaction.rs`): `Interaction::pointer` turns press/move/release into `UiEvent`s and remembers what is held, for the compositor.
- **Compositor** (`draw.rs`): `draw_main` / `draw_main_shade` / `render` blit sprites from a `Skin` following Webamp's selector rules.
- **Marquee and visualizer** (`marquee.rs`, `vis.rs`): time-driven by the app (`tick`, `frame`); `vis` is a port of Webamp's `VisPainter`.

**Tech Stack:** Rust 2024; `winrust-skin` and `rustfft` 6.4.1 as the only dependencies of `winrust-ui`; no windowing.

**Spec:** `docs/superpowers/specs/2026-10-11-m3-main-window-design.md` §4 (this part), §7 (decisions), with the umbrella spec `docs/superpowers/specs/2026-10-10-winrust-design.md` §5.1 and §7.5. Reference implementation: Webamp at commit 999f567 (`packages/webamp`).

**Scope:** M3 part 1 of 2. Part 2 (the `app` shell) gets its own plan.

## Global Constraints

- `winrust-ui` depends on `winrust-skin` and `rustfft` only: no winit, egui, audio or OS API (spec §4.1, umbrella §5.1).
- The canvas is `winrust_skin::Image` (32-bit `0xAARRGGBB`, 1× size); no second image type (spec §4.1).
- Coordinates are at 1×, from Webamp `css/main-window.css` at 999f567 (spec §4.2).
- "As Webamp" means the named Webamp file at 999f567 is the authority for exact values (spec header).
- Golden images (`WINRUST_BLESS=1`) must come out byte-identical on Windows, macOS and Linux, so nothing that feeds a golden image may use transcendental floating-point functions.
- `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings` and `cargo deny check` stay clean.
- Work on branch `m3-part1-ui`; commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Decisions fixed by this plan

These settle what the spec leaves open; each costs little to change later.

- **Line colouring:** each bar takes the colour of its top row (Winamp's line style). Webamp 999f567 draws its line mode as fire, marked FIXME.
- **Visualizer quirks kept from Webamp:**
  - bars and the scope sit 2 rows lower in the 16-row display ("push-down"), so bars are at most 13 rows tall;
  - in the shade display, zero peaks stay visible on the bottom row.
- **Double-size:** Webamp's double-size visualizer tweak (no push-down when doubled) is not ported. Winrust always composes at 1× and scales the whole window.
- **Shade mode** ignores the easter-egg title bar: Webamp's shade selectors take precedence.
- **Too-wide numbers:** kbps and kHz values wider than their 3- and 2-character cells are cut to the cell (1411 kbps shows "141").
- **Seek thumb** is hidden for non-seekable tracks (umbrella §6.4). Webamp leaves it at 0.
- **Golden images** use a fixed visualizer pattern. The real analyzer goes through `sin`/`cos`/`log10` and FFT twiddles, which may differ in the last bit between platforms; `vis.rs` tests cover it with assertions that do not depend on that.
- **Messages** in the marquee (spec §4.6) restart the scroll, and so does their expiry.
- **`skin-tool render`** draws without a visualizer frame.

## Review Focus

The inputs most likely to bite that the feature tests do not reach. Each has a test in the owning task:

1. **Skins with undersized sheets** (a 20×20 `main.bmp`, a 5×5 `cbuttons.bmp`): the window draws at full size, black past the bitmap, missing sprites from Winrust Base. Test: Task 8 `tiny_sheets_draw_black_or_base_pixels`.
2. **Pointer drags far outside the window** (±100 000 px): sliders clamp, and window moves report the full travel without overflow. Test: Task 5 `drags_far_outside_the_window_clamp`.
3. **Titles with characters `text.bmp` lacks** (CJK, emoji): drawn as spaces, one cell per character. Test: Task 8 `unmapped_characters_draw_as_spaces`.
4. **Out-of-range view values** (volume 255, balance −128, elapsed past the duration, seek fraction 2.0): clamped, never panicking. Test: Task 4 `out_of_range_values_are_clamped`.
5. **Short or broken audio input** (empty slices, NaN, infinities): the visualizer still draws a frame. Test: Task 7 `short_or_broken_input_draws_without_panicking`.

```rust
//! rules for the time, slider and bitrate displays (Webamp's, at 999f567).

use winrust_skin::Image;

#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]

    Buffering,
}

    #[default]
    Elapsed,
    Remaining,
}

#[derive(Clone, Debug, Default)]
pub struct MainView {
    pub state: PlayState,
    pub elapsed: Duration,
    /// `None` for streams, or while unknown.
    pub duration: Option<Duration>,
    pub time_mode: TimeMode,

    pub blink_hidden: bool,
    /// Scrolling text and how far it has scrolled, in pixels (see `Marquee`).
    pub title: String,
    pub title_offset: u32,
    pub kbps: Option<u32>,
    pub khz: Option<u32>,
    /// The source's channel count.
    pub channels: Option<u16>,
    /// 0..=100.
    pub volume: u8,

    pub balance: i8,

    pub eq: bool,
    pub playlist: bool,
    pub focused: bool,
    pub shade: bool,
    pub double_size: bool,
    pub always_on_top: bool,
    /// The "NO LLAMAS WERE HARMED"-style easter-egg title bar.
    pub easter_egg: bool,
    /// The visualizer's latest frame (76×16, or 38×5 in shade mode); `None` draws nothing.
    pub vis: Option<Image>,
}

/// The time display: four digits (m m : s s) and whether the minus sign shows.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct TimeDigits {
    pub minus: bool,
    pub digits: [u8; 4],
}

/// Elapsed time, or remaining time with a minus sign when the duration is known. Minutes
/// above 99 show as hours:minutes.
pub fn time_digits(elapsed: Duration, duration: Option<Duration>, mode: TimeMode) -> TimeDigits {
    let (secs, minus) = match (mode, duration) {
        (TimeMode::Remaining, Some(d)) => (d.saturating_sub(elapsed).as_secs(), true),
        _ => (elapsed.as_secs(), false),
    };
    let (hi, lo) = if secs / 60 > 99 {
        ((secs / 3600).min(99), secs / 60 % 60)
    } else {
        (secs / 60, secs % 60)
    };
    let digit = |n: u64| (n % 10) as u8;
    TimeDigits {
        minus,
        digits: [digit(hi / 10), digit(hi), digit(lo / 10), digit(lo)],
    }
}

/// Volume slider frame (Webamp `MainVolume.tsx`).
pub fn volume_frame(volume: u8) -> u32 {
    let sprite = (f32::from(volume.min(100)) * 28.0 / 100.0).round() as u32;
    sprite.saturating_sub(1).min(27)
}

/// Balance slider frame (Webamp `MainBalance.tsx`).
pub fn balance_frame(balance: i8) -> u32 {
    u32::from(balance.unsigned_abs().min(100)) * 27 / 100
}

/// Left edge of a slider's thumb within its track, for a value fraction 0..=1.
pub fn thumb_offset(track_width: u32, thumb_width: u32, fraction: f32) -> u32 {
    ((track_width - thumb_width) as f32 * fraction.clamp(0.0, 1.0)).round() as u32
}

pub fn volume_fraction(volume: u8) -> f32 {
    f32::from(volume.min(100)) / 100.0
}

pub fn balance_fraction(balance: i8) -> f32 {
    (f32::from(balance.clamp(-100, 100)) + 100.0) / 200.0
}

/// The seek bar's position: whole seconds over the duration, in whole percent (Webamp
/// `Position.tsx`).
pub fn seek_fraction(elapsed: Duration, duration: Duration) -> f32 {
    if duration.is_zero() {
        return 0.0;
    }
    let percent = elapsed.as_secs() as f64 / duration.as_secs_f64() * 100.0;
    (percent.round().min(100.0) / 100.0) as f32
}

/// The balance clips to the centre within 25% of it (Webamp `setBalance`).
pub fn snap_balance(balance: i8) -> i8 {
    if balance.unsigned_abs() < 25 {
        0
    } else {
        balance
    }
}

pub fn volume_text(volume: u8) -> String {
    format!("Volume: {volume}%")
}

pub fn balance_text(balance: i8) -> String {
    match balance {
        0 => "Balance: Center".into(),
        b if b > 0 => format!("Balance: {b}% Right"),
        b => format!("Balance: {}% Left", b.unsigned_abs()),
    }
}

/// What the title shows while the seek bar is dragged to `fraction` of `duration`.
pub fn seek_text(fraction: f32, duration: Duration) -> String {
    let percent = (fraction.clamp(0.0, 1.0) * 100.0).round() as u64;
    let to = duration.as_secs() * percent / 100;
    format!(
        "Seek to: {}/{} ({percent}%)",
        clock(to),
        clock(duration.as_secs())
    )
}

fn clock(secs: u64) -> String {
    format!("{:02}:{:02}", secs / 60, secs % 60)
}

/// Kilobits per second in the 3-character cell.
pub fn kbps_text(kbps: u32) -> String {
    format!("{kbps:>3}").chars().take(3).collect()
}

/// Kilohertz in the 2-character cell.
pub fn khz_text(khz: u32) -> String {
    format!("{khz:>2}").chars().take(2).collect()
}
```

```rust
//! Pointer handling for the main window: press, drag and release become [`UiEvent`]s, and
//! the compositor asks which button shows pressed and which slider is being dragged.

use crate::layout::{self, Kind, Mode, Widget};
use crate::view::{self, MainView, PlayState};

#[derive(Clone, Copy, Debug, PartialEq)]
pub enum Pointer {
    /// The left button went down at a 1× window point; `double` marks the second press of
    /// a double-click.
    Down {
        x: i32,
        y: i32,
        double: bool,
    },
    Move {
        x: i32,
        y: i32,
    },
    Up {
        x: i32,
        y: i32,
    },
}

#[derive(Clone, Copy, Debug, PartialEq)]
pub enum UiEvent {
    /// A button was released over itself.
    Clicked(Widget),
    Volume(u8),
    Balance(i8),
    /// Seek to this fraction of the track; sent when the seek bar is released.
    Seek(f32),
    /// Move the window by the pointer's travel since the title bar was pressed (1× pixels).
    MoveWindow {
        dx: i32,
        dy: i32,
    },
    /// The title bar was double-clicked.
    ToggleShade,
    /// The title text was dragged this many pixels since the last event.
    DragTitle(i32),
    DragTitleEnd,
}

#[derive(Clone, Copy, Debug, Default, PartialEq)]
enum Grab {
    #[default]
    None,
    Button {
        widget: Widget,
        over: bool,
    },
    /// `offset` is where the thumb was taken, from its left edge.
    Slider {
        widget: Widget,
        offset: i32,
        fraction: f32,
    },
    Window {
        x: i32,
        y: i32,
    },
    Title {
        x: i32,
    },
}

const TITLE_BUTTONS: [Widget; 4] = [
    Widget::Options,
    Widget::Minimize,
    Widget::Shade,
    Widget::Close,
];

#[derive(Clone, Debug, Default)]
pub struct Interaction {
    grab: Grab,
    /// Which title buttons have been pressed at least once.
    clicked: [bool; 4],
}

impl Interaction {
    pub fn new() -> Self {
        Self::default()
    }

    pub fn pointer(&mut self, event: Pointer, view: &MainView) -> Option<UiEvent> {
        let mode = if view.shade {
            Mode::Shade
        } else {
            Mode::Normal
        };
        match event {
            Pointer::Down { x, y, double } => self.down(mode, x, y, double, view),
            Pointer::Move { x, y } => self.moved(mode, x, y),
            Pointer::Up { x, y } => self.up(mode, x, y),
        }
    }

    /// The button drawn pressed: held, with the pointer over it.
    pub fn pressed(&self) -> Option<Widget> {
        match self.grab {
            Grab::Button { widget, over: true } => Some(widget),
            _ => None,
        }
    }

    /// The slider being dragged, with its value as a fraction of its track.
    pub fn sliding(&self) -> Option<(Widget, f32)> {
        match self.grab {
            Grab::Slider {
                widget, fraction, ..
            } => Some((widget, fraction)),
            _ => None,
        }
    }

    /// Whether a title button (options, minimize, shade, close) has been pressed yet. Until
    /// then the title bar shows through it (Webamp `ClickedDiv.tsx`).
    pub fn title_button_clicked(&self, widget: Widget) -> bool {
        TITLE_BUTTONS
            .iter()
            .position(|&w| w == widget)
            .is_some_and(|i| self.clicked[i])
    }

    fn down(
        &mut self,
        mode: Mode,
        x: i32,
        y: i32,
        double: bool,
        view: &MainView,
    ) -> Option<UiEvent> {
        self.grab = Grab::None;
        let widget = layout::hit_test(mode, x, y)?;
        if double && widget == Widget::TitleBar {
            return Some(UiEvent::ToggleShade);
        }
        match widget.kind() {
            Kind::Button => {
                if let Some(i) = TITLE_BUTTONS.iter().position(|&w| w == widget) {
                    self.clicked[i] = true;
                }
                self.grab = Grab::Button { widget, over: true };
                None
            }
            Kind::Drag if widget == Widget::TitleBar => {
                self.grab = Grab::Window { x, y };
                None
            }
            Kind::Drag => {
                self.grab = Grab::Title { x };
                Some(UiEvent::DragTitle(0))
            }
            Kind::Slider => {
                let fraction = slider_value(widget, view)?;
                let track = layout::rect(mode, widget)?;
                let thumb = layout::thumb_width(mode, widget);
                let left = (track.x + view::thumb_offset(track.w, thumb, fraction)) as i32;
                let on_thumb = x >= left && x < left + thumb as i32;
                let offset = if on_thumb {
                    x - left
                } else {
                    (thumb / 2) as i32
                };
                self.grab = Grab::Slider {
                    widget,
                    offset,
                    fraction,
                };
                if on_thumb { None } else { self.slide(mode, x) }
            }
        }
    }

    fn moved(&mut self, mode: Mode, x: i32, y: i32) -> Option<UiEvent> {
        match self.grab {
            Grab::None => None,
            Grab::Button { widget, .. } => {
                let over = layout::rect(mode, widget).is_some_and(|r| layout::contains(r, x, y));
                self.grab = Grab::Button { widget, over };
                None
            }
            Grab::Slider { .. } => self.slide(mode, x),
            Grab::Window { x: gx, y: gy } => Some(UiEvent::MoveWindow {
                dx: x - gx,
                dy: y - gy,
            }),
            Grab::Title { x: last } => {
                self.grab = Grab::Title { x };
                (x != last).then_some(UiEvent::DragTitle(x - last))
            }
        }
    }

    fn up(&mut self, mode: Mode, x: i32, y: i32) -> Option<UiEvent> {
        match std::mem::take(&mut self.grab) {
            Grab::Button { widget, .. } => layout::rect(mode, widget)
                .filter(|&r| layout::contains(r, x, y))
                .map(|_| UiEvent::Clicked(widget)),
            Grab::Slider {
                widget: Widget::Seek,
                fraction,
                ..
            } => Some(UiEvent::Seek(fraction)),
            Grab::Title { .. } => Some(UiEvent::DragTitleEnd),
            _ => None,
        }
    }

    /// Moves the grabbed thumb so the grab point is under `x`; reports a changed volume or
    /// balance (the seek bar reports on release).
    fn slide(&mut self, mode: Mode, x: i32) -> Option<UiEvent> {
        let Grab::Slider {
            widget,
            offset,
            fraction,
        } = self.grab
        else {
            return None;
        };
        let track = layout::rect(mode, widget)?;
        let travel = track.w - layout::thumb_width(mode, widget);
        let new = ((x - offset - track.x as i32) as f32 / travel as f32).clamp(0.0, 1.0);
        self.grab = Grab::Slider {
            widget,
            offset,
            fraction: new,
        };
        let after = slider_event(widget, new);

            after
        } else {
            None
        }
    }
}

fn slider_value(widget: Widget, view: &MainView) -> Option<f32> {
    match widget {
        Widget::Volume => Some(view::volume_fraction(view.volume)),
        Widget::Balance => Some(view::balance_fraction(view.balance)),
        Widget::Seek => {
            let enabled = view.seekable && view.state != PlayState::Stopped;
            let duration = view.duration.filter(|_| enabled)?;
            Some(view::seek_fraction(view.elapsed, duration))
        }
        _ => None,
    }
}

fn slider_event(widget: Widget, fraction: f32) -> Option<UiEvent> {
    match widget {
        Widget::Volume => Some(UiEvent::Volume((fraction * 100.0).round() as u8)),
        Widget::Balance => {
            let balance = (fraction * 200.0 - 100.0).round() as i8;
            Some(UiEvent::Balance(view::snap_balance(balance)))
        }
        _ => None,
    }
}
```

```rust
//! The scrolling song title (Webamp `Marquee.tsx`): text longer than the marquee loops with a
//! separator, stepping one 5-pixel character every 220 ms. Dragging scrubs it and pauses the
//! stepping until a second after the drag ends. The app drives time with [`Marquee::tick`].

use std::time::Duration;

pub const STEP: Duration = Duration::from_millis(220);
pub const RESUME_AFTER: Duration = Duration::from_secs(1);
pub const MESSAGE_FOR: Duration = Duration::from_secs(3);
pub const SEPARATOR: &str = "  ***  ";
const CHAR_WIDTH: u32 = 5;
/// Texts this long (or longer) do not fit the 154-pixel marquee and scroll.
const LONG: usize = 31;

/// Winamp's title line: `"<n>. <title> (<m:ss>)"`, without the time for streams.
pub fn track_title(number: usize, title: &str, duration: Option<Duration>) -> String {
    match duration {
        Some(d) => {
            let s = d.as_secs();
            format!("{number}. {title} ({}:{:02})", s / 60, s % 60)
        }
        None => format!("{number}. {title}"),
    }
}

fn is_long(text: &str) -> bool {
    text.chars().count() >= LONG
}

/// What the marquee draws: long text twice around the separator, so the loop is seamless.
pub fn looped(text: &str) -> String {
    if is_long(text) {
        format!("{text}{SEPARATOR}{text}")
    } else {
        text.to_string()
    }
}

#[derive(Clone, Debug, Default)]
pub struct Marquee {
    text: String,
    /// A message shown instead of the text, with the time it has left.
    message: Option<(String, Duration)>,
    step: u32,
    /// Pixels the text was dragged by, positive to the left.
    scrub: i32,
    since_step: Duration,
    /// Time left before stepping resumes after a drag.
    hold: Duration,
    dragging: bool,
}

impl Marquee {
    pub fn new() -> Self {
        Self::default()
    }

    /// Replaces the text; a different text starts from the beginning.
    pub fn set_text(&mut self, text: &str) {
        if text != self.text {
            self.text = text.to_string();
            self.restart();
        }
    }

    /// Shows `message` instead of the text for [`MESSAGE_FOR`].
    pub fn show_message(&mut self, message: &str) {
        self.message = Some((message.to_string(), MESSAGE_FOR));
        self.restart();
    }

    fn restart(&mut self) {
        self.step = 0;
        self.scrub = 0;
        self.since_step = Duration::ZERO;
    }

    /// The text shown now (a message, or the title).
    pub fn text(&self) -> &str {
        match &self.message {
            Some((message, _)) => message,
            None => &self.text,
        }
    }

    /// How far the looped text is scrolled, in pixels.
    pub fn offset(&self) -> u32 {
        let text = self.text();
        if !is_long(text) {
            return 0;
        }
        let width = ((text.chars().count() + SEPARATOR.len()) as u32 * CHAR_WIDTH) as i64;
        (i64::from(self.step) * i64::from(CHAR_WIDTH) + i64::from(self.scrub)).rem_euclid(width)
            as u32
    }

    /// Advances time by `dt`.
    pub fn tick(&mut self, mut dt: Duration) {
        if let Some((_, left)) = &mut self.message {
            if dt < *left {
                *left -= dt;
            } else {
                self.message = None;
                self.restart();
            }
        }
        if self.dragging {
            return;
        }
        if self.hold > Duration::ZERO {
            if dt < self.hold {
                self.hold -= dt;
                return;
            }
            dt -= self.hold;
            self.hold = Duration::ZERO;
            self.since_step = Duration::ZERO;
        }
        self.since_step += dt;
        while self.since_step >= STEP {
            self.since_step -= STEP;
            self.step += 1;
        }
    }

    /// The pointer dragged the text `dx` pixels (positive to the right).
    pub fn drag(&mut self, dx: i32) {
        self.dragging = true;
        self.scrub -= dx;
    }

    pub fn end_drag(&mut self) {
        self.dragging = false;
        self.hold = RESUME_AFTER;
    }
}
```

```rust
const BINS: usize = 512;

#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]

    Off,

            VisMode::Oscilloscope => VisMode::Off,
            VisMode::Off => VisMode::Spectrum,

            Falloff::Slow => 6.0,
            Falloff::Moderate => 12.0,
            Falloff::Fast => 16.0,

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct VisSettings {
    pub mode: VisMode,
    pub bandwidth: Bandwidth,
    pub coloring: Coloring,
    pub osc_style: OscStyle,
    pub peaks: bool,
    pub falloff: Falloff,
    pub peak_falloff: Falloff,
}

impl Default for VisSettings {
    fn default() -> Self {
        VisSettings {
            mode: VisMode::Spectrum,
            bandwidth: Bandwidth::Wide,
            coloring: Coloring::Normal,
            osc_style: OscStyle::Lines,
            peaks: true,
            falloff: Falloff::Moderate,
            peak_falloff: Falloff::Slow,
        }
    }
}

pub struct Vis {
    pub settings: VisSettings,
    fft: Arc<dyn Fft<f32>>,
    window: Vec<f32>,
    equalize: Vec<f32>,
    /// Per column: the falling bar, the peak (in 1/256 rows) and the peak's fall speed.
    bars: [f32; 76],
    peaks: [i32; 76],
    peak_speed: [f32; 76],
    /// The mode and size the state above belongs to.
    last: Option<(VisMode, bool)>,
}

impl Vis {
    pub fn new(settings: VisSettings) -> Self {
        // FFTNullsoft's envelope is a Hann window; here it spans the 576 frames.
        let window = (0..FRAMES)
            .map(|i| 0.5 - 0.5 * (std::f32::consts::TAU * i as f32 / FRAMES as f32).cos())
            .collect();
        // FFTNullsoft's equalization: lifts the high bins on a log curve.
        let mut bias = 0.04f32;
        let equalize = (0..BINS)
            .map(|i| {
                let step = (9.0 - bias) / BINS as f32;
                let e = (1.0 + bias + (i + 1) as f32 * step).log10();
                bias /= 1.0025;
                e
            })
            .collect();
        Vis {
            settings,
            fft: FftPlanner::new().plan_fft_forward(FFT_SIZE),
            window,
            equalize,
            bars: [0.0; 76],
            peaks: [0; 76],
            peak_speed: [0.0; 76],
            last: None,
        }
    }

    /// Draws one frame from the latest [`FRAMES`] frames of each channel: 76×16, or 38×5
    /// when `small` (shade mode). `None` when the mode is off.
    pub fn frame(
        &mut self,
        left: &[f32],
        right: &[f32],
        colors: &[u32; 24],
        small: bool,
    ) -> Option<Image> {
        let mode = self.settings.mode;
        if mode == VisMode::Off {
            return None;
        }
        if self.last != Some((mode, small)) {
            self.bars = [0.0; 76];
            self.peaks = [0; 76];
            self.peak_speed = [0.0; 76];
            self.last = Some((mode, small));
        }
        let bytes = time_bytes(left, right);
        let mut img = background(colors, small);
        match mode {
            VisMode::Spectrum => self.spectrum(&bytes, colors, small, &mut img),
            VisMode::Oscilloscope => self.oscilloscope(&bytes, colors, small, &mut img),
            VisMode::Off => {}
        }
        Some(img)
    }

    fn spectrum(&mut self, bytes: &[u8; FRAMES], colors: &[u32; 24], small: bool, img: &mut Image) {
        let mut buf = vec![Complex::new(0.0f32, 0.0); FFT_SIZE];
        // Webamp feeds 1024 samples; the scale keeps a 576-frame window's magnitudes the same.
        let scale = FFT_SIZE as f32 / FRAMES as f32 / 24.0;
        for (i, b) in bytes.iter().enumerate() {
            buf[i].re = (f32::from(*b) - 128.0) * scale * self.window[i];
        }
        self.fft.process(&mut buf);
        let spectral: Vec<f32> = (0..BINS)
            .map(|i| buf[i].norm() * self.equalize[i])
            .collect();

        let (target, max_height, max_width) = if small { (40, 5.0, 37) } else { (75, 15.0, 75) };
        let push_down = if small { 0 } else { 2 };
        let mut sample = [0.0f32; 76];
        let log_max = (BINS as f32).log10();
        for (x, s) in sample.iter_mut().enumerate().take(target) {
            // Webamp blends a linear and a log scale (0.91 log) to place bins on columns.
            let t = x as f32 / (target - 1) as f32;
            let linear = t * (BINS - 1) as f32;
            let log = 10f32.powf(log_max * t);
            let index = 0.09 * linear + 0.91 * log;
            let i1 = (index.floor() as usize).min(BINS - 1);
            let i2 = (index.ceil() as usize).min(BINS - 1);
            *s = if i1 == i2 {
                spectral[i1]
            } else {
                let f = index - i1 as f32;
                (1.0 - f) * spectral[i1] + f * spectral[i2]
            };
        }

        let wide = self.settings.bandwidth == Bandwidth::Wide;
        let falloff = self.settings.falloff.bars() / 16.0;
        let peak_falloff = self.settings.peak_falloff.peaks();
        for x in 0..max_width {
            let chunk = if wide { x & !3 } else { 0 };
            let data = if wide {
                (sample[chunk..chunk + 4].iter().sum::<f32>() / 4.0).trunc()
            } else {
                sample[x].trunc()
            }
            .min(max_height);
            self.peaks[x] = self.peaks[x].min(max_height as i32 * 256);
            self.bars[x] -= falloff;
            if self.bars[x] <= data {
                self.bars[x] = data;
            }
            if self.peaks[x] <= js_round(self.bars[x] * 256.0) {
                self.peaks[x] = (self.bars[x] * 256.0) as i32;
                self.peak_speed[x] = 3.0;
            }
            let mut bar_peak = self.peaks[x] / 256;
            self.peaks[x] -= js_round(self.peak_speed[x]);
            self.peak_speed[x] *= peak_falloff;
            if self.peaks[x] <= 0 {
                self.peaks[x] = 0;
            }
            // Webamp keeps zero peaks visible in the small display only.
            if !small && bar_peak < 1 {
                bar_peak = -3;
            }
            if !(wide && x == chunk + 3) {
                let height = js_round(self.bars[x]) - push_down;
                self.paint_bar(
                    img,
                    colors,
                    small,
                    x as u32,
                    height,
                    bar_peak + 1 - push_down,
                );
            }
        }
    }

    fn paint_bar(
        &self,
        img: &mut Image,
        colors: &[u32; 24],
        small: bool,
        x: u32,
        height: i32,
        peak: i32,
    ) {
        let h = img.height as i32;
        // Bar colour by row: viscolor 0-15 (Webamp's push-down shifts them two rows), or five
        // of them in the small display.
        let row_color = |row: i32| -> u32 {
            if small {
                colors[[4, 8, 11, 14, 17][row.clamp(0, 4) as usize]]
            } else {
                colors[row.clamp(0, 15) as usize]
            }
        };
        let top = h - height;
        for y in top.max(0)..h {
            let c = match self.settings.coloring {
                Coloring::Normal => row_color(y),
                Coloring::Fire => row_color(y - top),
                Coloring::Line => row_color(top),
            };
            img.set(x, y as u32, c);
        }
        let peak_y = h - peak;
        if self.settings.peaks && (0..h).contains(&peak_y) {
            img.set(x, peak_y as u32, colors[23]);
        }
    }

    fn oscilloscope(
        &mut self,
        bytes: &[u8; FRAMES],
        colors: &[u32; 24],
        small: bool,
        img: &mut Image,
    ) {
        let width = if small { 38 } else { 75 };
        let push_down = if small { 0 } else { 2 };
        let slice = FRAMES / 75;
        let mut last_y = 0;
        for x in 0..width {
            let amplitude = i32::from(bytes[slice * x]);
            let mut y = js_round(amplitude as f32 / 8.0) - 9;
            if small {
                y -= 5;
                y = js_round((y + 11) as f32 / 16.0 * 5.0) - 2;
            }
            let y = y.clamp(0, img.height as i32 - 1);
            if x == 0 {
                last_y = y;
            }
            let (mut top, mut bottom) = (y, last_y);
            last_y = y;
            match self.settings.osc_style {
                OscStyle::Solid => {
                    let middle = if small { 2 } else { 8 };
                    (top, bottom) = if y >= middle {
                        (middle, y)
                    } else {
                        (y, if small { 2 } else { 7 })
                    };
                    if x == 0 && small {
                        (top, bottom) = (y, y);
                    }
                }
                OscStyle::Dots => bottom = y,
                OscStyle::Lines => {
                    if bottom < top {
                        (top, bottom) = (bottom, top);
                        if !small {
                            top += 1;
                        }
                    }
                }
            }
            let c = colors[18 + scope_color(y, small)];
            for row in top..=bottom {
                img.set(x as u32, (row + push_down) as u32, c);
            }
        }
    }
}

/// The tap as Web Audio's byte time-domain data: mono, 128 ± 128.
fn time_bytes(left: &[f32], right: &[f32]) -> [u8; FRAMES] {
    let mut out = [128u8; FRAMES];
    for (i, b) in out.iter_mut().enumerate() {
        let l = left.get(i).copied().unwrap_or(0.0);
        let r = right.get(i).copied().unwrap_or(0.0);
        *b = (128.0 * (1.0 + (l + r) / 2.0)).floor().clamp(0.0, 255.0) as u8;
    }
    out
}

/// Colour 0 dotted with colour 1 on every other pixel and row; plain in the small display.
fn background(colors: &[u32; 24], small: bool) -> Image {
    if small {
        return Image::new(38, 5, colors[0]);
    }
    let mut img = Image::new(76, 16, colors[0]);
    for y in (1..16).step_by(2) {
        for x in (0..76).step_by(2) {
            img.set(x, y, colors[1]);
        }
    }
    img
}

/// Webamp's oscilloscope colour (0..=4 into viscolor 18-22) for a row.
fn scope_color(y: i32, small: bool) -> usize {
    match y {
        _ if small => 0,
        14.. => 4,
        12.. => 3,
        10.. => 2,
        8.. => 1,
        6.. => 0,
        4.. => 1,
        2.. => 2,
        _ => 3,
    }
}

/// JavaScript's `Math.round`: halves round up.
fn js_round(v: f32) -> i32 {
    (v + 0.5).floor() as i32
}
```

Webamp's rules, as the tests pin them:

```rust
//! The compositor: draws the main window at 1× from a skin, a [`MainView`] and the pointer
//! state. Which sprite shows when follows Webamp's `skinSelectors.ts` and CSS at 999f567.

use crate::interaction::Interaction;
use crate::layout::{self, Mode, Widget};
use crate::marquee;
use crate::view::{self, MainView, PlayState};
use winrust_skin::{Image, Rect, Skin, SpriteId as S, SpriteRef};

/// The main window in the mode `view` asks for, as a new image.
pub fn render(skin: &Skin, view: &MainView, ui: &Interaction) -> Image {
    let mode = if view.shade {
        Mode::Shade
    } else {
        Mode::Normal
    };
    let (w, h) = mode.size();
    let mut out = Image::new(w, h, winrust_skin::image::BLACK);
    if view.shade {
        draw_main_shade(skin, view, ui, &mut out);
    } else {
        draw_main(skin, view, ui, &mut out);
    }
    out
}

/// Draws the normal main window into `out` (275×116).
pub fn draw_main(skin: &Skin, view: &MainView, ui: &Interaction, out: &mut Image) {

    let bar = match (view.easter_egg, view.focused) {

        (true, false) => S::MainEasterEggTitleBar,

/// Draws the shade-mode bar into `out` (275×14).
pub fn draw_main_shade(skin: &Skin, view: &MainView, ui: &Interaction, out: &mut Image) {
    let bar = if view.focused {
        S::MainShadeBackgroundSelected
    } else {
        S::MainShadeBackground
    };
    put(out, skin.sprite(bar), 0, 0);
    title_buttons(skin, view, ui, Mode::Shade, out);
    if let Some(vis) = view.vis.as_ref().filter(|v| (v.width, v.height) == (38, 5)) {
        out.blit(vis, Rect::new(0, 0, 38, 5), 79, 5);
    }
    if time_shown(view) {
        let t = view::time_digits(view.elapsed, view.duration, view.time_mode);
        let digit = |i: usize| char::from(b'0' + t.digits[i]);
        let chars = [
            if t.minus { '-' } else { ' ' },
            digit(0),
            digit(1),
            digit(2),
            digit(3),
        ];
        for (c, left) in chars.into_iter().zip([1, 7, 12, 20, 25]) {
            glyph(out, skin, c, 127 + left, 4, Rect::new(0, 0, 275, 14));
        }
    }
    seek_bar(skin, view, ui, Mode::Shade, out);
}

fn put(out: &mut Image, s: SpriteRef, x: u32, y: u32) {
    out.blit(s.image, s.rect, x, y);
}

/// The `w`×`h` top-left part of a sprite: Webamp shows some sprites in a smaller box.
fn put_part(out: &mut Image, s: SpriteRef, w: u32, h: u32, x: u32, y: u32) {
    let r = Rect::new(s.rect.x, s.rect.y, w.min(s.rect.w), h.min(s.rect.h));
    out.blit(s.image, r, x, y);
}

/// A sprite at its widget's place.
fn put_at(out: &mut Image, s: SpriteRef, mode: Mode, widget: Widget) {
    if let Some(r) = layout::rect(mode, widget) {
        put_part(out, s, r.w, r.h, r.x, r.y);
    }
}

/// A `text.bmp` glyph with its top-left corner at (x, y), cut to `clip`.
fn glyph(out: &mut Image, skin: &Skin, c: char, x: i32, y: u32, clip: Rect) {
    let g = skin.glyph(c);
    for dy in 0..g.rect.h {
        for dx in 0..g.rect.w {
            let px = x + dx as i32;
            if layout::contains(clip, px, (y + dy) as i32) {
                let color = g.image.get(g.rect.x + dx, g.rect.y + dy);
                out.set(px as u32, y + dy, color);
            }
        }
    }
}

fn text(out: &mut Image, skin: &Skin, s: &str, x: i32, y: u32, clip: Rect) {
    for (i, c) in s.chars().enumerate() {
        glyph(out, skin, c, x + 5 * i as i32, y, clip);
    }
}

/// Title buttons show the title bar until first pressed, and only in the focused window
/// (Webamp `.selected #title-bar #close.clicked`). In shade mode the shade button always
/// shows its "unshade" sprite when focused.
fn title_buttons(skin: &Skin, view: &MainView, ui: &Interaction, mode: Mode, out: &mut Image) {
    let shade_mode = mode == Mode::Shade;
    let buttons = [
        (
            Widget::Options,
            S::MainOptionsButton,
            S::MainOptionsButtonDepressed,
        ),
        (
            Widget::Minimize,
            S::MainMinimizeButton,
            S::MainMinimizeButtonDepressed,
        ),
        (
            Widget::Shade,
            S::MainShadeButton,
            S::MainShadeButtonDepressed,
        ),
        (
            Widget::Close,
            S::MainCloseButton,
            S::MainCloseButtonDepressed,
        ),
    ];
    for (widget, up, down) in buttons {

        } else {

        if let Some(id) = sprite {
            put_at(out, skin.sprite(id), mode, widget);
        }
    }
}

/// The play/pause/stop indicator and, beside it, the 3-pixel work indicator: "not
/// working" while playing, "working" (with no play indicator) while buffering.
fn play_state(skin: &Skin, view: &MainView, out: &mut Image) {
    let indicator = match view.state {
        PlayState::Playing => Some(S::MainPlayingIndicator),
        PlayState::Paused => Some(S::MainPausedIndicator),
        PlayState::Stopped => Some(S::MainStoppedIndicator),
        PlayState::Buffering => None,
    };
    if let Some(id) = indicator {
        put(out, skin.sprite(id), 26, 28);
    }
    let work = match view.state {
        PlayState::Playing => Some(S::MainNotWorkingIndicator),
        PlayState::Buffering => Some(S::MainWorkingIndicator),
        _ => None,
    };
    if let Some(id) = work {
        put_part(out, skin.sprite(id), 3, 9, 24, 28);
    }
}

/// Hidden while stopped, and during the hidden half of the paused blink.

    match view.state {
        PlayState::Stopped => false,
        PlayState::Paused => !view.blink_hidden,
        _ => true,
    }
}

/// The time: `nums_ex` draws a whole 9×13 minus cell at (38, 26); `numbers` a 5×1 minus
/// at (38, 32). The colon is part of the background.
fn time(skin: &Skin, view: &MainView, out: &mut Image) {
    if !time_shown(view) {
        return;
    }
    let t = view::time_digits(view.elapsed, view.duration, view.time_mode);
    let ex = skin.uses_nums_ex();
    match (ex, t.minus) {
        (true, true) => put(out, skin.sprite(S::MinusSignEx), 38, 26),
        (true, false) => put(out, skin.sprite(S::NoMinusSignEx), 38, 26),
        (false, true) => put(out, skin.sprite(S::MinusSign), 38, 32),
        (false, false) => put(out, skin.sprite(S::NoMinusSign), 38, 32),
    }
    let digits = if ex { &DIGITS_EX } else { &DIGITS };
    for (d, x) in t.digits.iter().zip([48, 60, 78, 90]) {
        put(out, skin.sprite(digits[*d as usize]), x, 26);
    }
}

/// The seek bar; its thumb shows only while a seekable track plays or pauses. In shade mode
/// the thumb has left, middle and right sprites (Webamp `Position.tsx`).
fn seek_bar(skin: &Skin, view: &MainView, ui: &Interaction, mode: Mode, out: &mut Image) {
    let shade = mode == Mode::Shade;
    let background = if shade {
        S::MainShadePositionBackground
    } else {
        S::MainPositionSliderBackground
    };
    put_at(out, skin.sprite(background), mode, Widget::Seek);
    let Some(duration) = view
        .duration
        .filter(|_| view.seekable && view.state != PlayState::Stopped)
    else {
        return;
    };
    let dragged = ui.sliding().filter(|(w, _)| *w == Widget::Seek);
    let fraction = dragged.map_or(view::seek_fraction(view.elapsed, duration), |(_, f)| f);
    let thumb = match (shade, dragged.is_some()) {
        (false, false) => S::MainPositionSliderThumb,
        (false, true) => S::MainPositionSliderThumbSelected,
        (true, _) if fraction <= 0.33 => S::MainShadePositionThumbLeft,
        (true, _) if fraction >= 0.66 => S::MainShadePositionThumbRight,
        (true, _) => S::MainShadePositionThumb,
    };
    let Some(track) = layout::rect(mode, Widget::Seek) else {
        return;
    };
    let width = layout::thumb_width(mode, Widget::Seek);
    let x = track.x + view::thumb_offset(track.w, width, fraction);
    put(out, skin.sprite(thumb), x, track.y);
}
```

```rust
/// Compares `img` with `tests/golden/<name>.png`. `WINRUST_BLESS=1` rewrites the file.
pub fn assert_golden(name: &str, img: &Image) {
    let path: PathBuf = [
        env!("CARGO_MANIFEST_DIR"),
        "tests",
        "golden",
        &format!("{name}.png"),
    ]
    .iter()
    .collect();
    if std::env::var_os("WINRUST_BLESS").is_some() {
        std::fs::create_dir_all(path.parent().unwrap()).unwrap();
        std::fs::write(&path, img.to_png()).unwrap();
        return;
    }
    let expected = std::fs::read(&path)
        .ok()
        .and_then(|png| bmp::decode_any(&png).ok())
        .unwrap_or_else(|| panic!("missing {}; run with WINRUST_BLESS=1", path.display()));
    if expected != *img {
        let actual = Path::new(env!("CARGO_TARGET_TMPDIR")).join(format!("{name}.actual.png"));
        std::fs::write(&actual, img.to_png()).unwrap();
        let differ = if (expected.width, expected.height) == (img.width, img.height) {
            let n = expected
                .pixels
```

```rust
//! Skin development tools.
//!
//! `cargo run -p winrust-ui --example skin-tool -- contact <skin.wsz|dir> <out.png>`
//! `cargo run -p winrust-ui --example skin-tool -- debug-wsz <out.wsz>`
//! `cargo run -p winrust-ui --example skin-tool -- render <skin|base|debug> <state> <out.png>`
//!
//! `render` draws the main window in one state: stopped, playing, paused, buffering or shade.
//! The skin is a `.wsz`, `.zip` or folder, or one of the built-in skins.

use std::path::Path;
use std::process::ExitCode;
use std::sync::Arc;
use std::time::Duration;
use winrust_skin::{Skin, contact_sheet, debug};
use winrust_ui::draw;
use winrust_ui::interaction::Interaction;
use winrust_ui::view::{MainView, PlayState};

fn main() -> ExitCode {
    let args: Vec<String> = std::env::args().skip(1).collect();
    let args: Vec<&str> = args.iter().map(String::as_str).collect();
    let result = match args.as_slice() {
        ["contact", skin, out] => load(skin).and_then(|s| write(out, &contact_sheet(&s))),
        ["debug-wsz", out] => std::fs::write(out, debug::wsz()).map_err(|e| e.to_string()),
        ["render", skin, state, out] => load(skin).and_then(|s| render(&s, state, out)),
        _ => Err(
            "usage: skin-tool contact <skin> <out.png> | debug-wsz <out.wsz> \
                  | render <skin|base|debug> <stopped|playing|paused|buffering|shade> <out.png>"
                .into(),
        ),
    };
    match result {
        Ok(()) => ExitCode::SUCCESS,
        Err(e) => {
            eprintln!("{e}");
            ExitCode::FAILURE
        }
    }
}

/// A skin file or folder, or the built-in `base` or `debug` skin.
fn load(skin: &str) -> Result<Arc<Skin>, String> {
    let skin = match skin {
        "base" => return Ok(Skin::base()),
        "debug" => return Ok(Arc::new(Skin::debug())),
        path => Skin::load(Path::new(path)).map_err(|e| e.to_string())?,
    };
    for warning in &skin.warnings {
        eprintln!("warning: {warning}");
    }
    Ok(Arc::new(skin))
}

fn write(out: &str, img: &winrust_skin::Image) -> Result<(), String> {
    std::fs::write(out, img.to_png()).map_err(|e| e.to_string())
}

fn render(skin: &Skin, state: &str, out: &str) -> Result<(), String> {
    let playing = MainView {
        state: PlayState::Playing,
        elapsed: Duration::from_secs(83),
        duration: Some(Duration::from_secs(296)),
        title: "1. Artist - Title (4:56)".into(),
        kbps: Some(128),
        khz: Some(44),
        channels: Some(2),
        volume: 75,
        seekable: true,
        focused: true,
        ..MainView::default()
    };
    let view = match state {
        "stopped" => MainView {
            title: "Winrust".into(),
            focused: true,
            ..MainView::default()
        },
        "playing" => playing,
        "paused" => MainView {
            state: PlayState::Paused,
            ..playing
        },
        "buffering" => MainView {
            state: PlayState::Buffering,
            title: "1. Radio stream".into(),
            duration: None,
            seekable: false,
            ..playing
        },
        "shade" => MainView {
            shade: true,
            ..playing
        },
        other => return Err(format!("unknown state {other}")),
    };
    write(out, &draw::render(skin, &view, &Interaction::new()))
}
```
