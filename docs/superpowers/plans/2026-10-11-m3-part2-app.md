# M3 Part 2: Winrust App Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `crates/app` into the `winrust` player: a borderless winit + softbuffer window that draws the main window with `winrust-ui`, plays files, folders and streams given on the command line or dropped on it, follows the hotkey table and keeps a minimal `config.toml`. Two engine changes the shell needs come first.

**Architecture:**
- **Engine** (`crates/audio`): a stalled stream no longer blocks the decode thread (it decodes only while enough bytes wait in the network pipe); a new `Command::Unqueue` takes back a gapless `QueueNext`.
- **Pure app library** (`winrust_app`, `crates/app/src/lib.rs`), all tested without a window:
  - `queue` and `sources`: what plays next, and what the command line or a drop means;
  - `model`: `Model`, `Action`, `Control`, `Effect`, and `Model::apply(action, now) -> Vec<Effect>`;
  - `input`: the hotkey table, the mouse wheel and double-click detection;
  - `config`: `config.toml`, the save debounce and window placement;
  - `present`: scaling and the pixel copy into the window.
- **Binary** (`crates/app/src/main.rs`): a winit `ApplicationHandler` that turns window and engine events into `Action`s and carries out the `Effect`s. It decides nothing itself.

**Tech Stack:** Rust 2024; winit 0.30.13 (X11 only on Linux), softbuffer 0.4.8, directories 6.0.0, serde 1.0.229, toml 1.1.8; tempfile for tests.

**Spec:** `docs/superpowers/specs/2026-10-11-m3-main-window-design.md` §5 (this part), §6 (hotkeys), §7; umbrella `docs/superpowers/specs/2026-10-10-winrust-design.md` §5.3, §5.4, §6.7, §8.3, §9.4, §10. Reference implementation: Webamp at commit 999f567 (`packages/webamp`).

**Scope:** M3 part 2 of 2. It builds on part 1 (`winrust-ui`, PR #4), so the branch starts from `m3-part1-ui`.

**Provenance:** every code block below was compiled and tested on Windows 11 with Rust 1.99 before the plan was written, and the plan was then replayed on a fresh clone, checking every RED and GREEN. Final suite: 397 passed, 1 ignored; `fmt`, `clippy -D warnings` and `cargo deny` clean. The window was launched on Windows, both empty and playing a silent WAV, and drew correctly. ## Global Constraints

- `winrust-audio`, `winrust-skin` and `winrust-ui` gain no windowing dependency; winit and softbuffer appear only in `crates/app` (umbrella §5.1).
- App decisions live in the `winrust_app` library and are tested without a window. `main.rs` only translates, and the window holds no state beyond OS handles (umbrella §5.3).
- One borderless window: 275×116, or 275×14 in shade. Present scale = `max(1, round(OS scale factor)) × (2 if double-size)`, nearest-neighbour (spec §5.2).
- On Linux the X11 backend is forced (spec §5.2, umbrella §8.3).
- Idle is event-driven with zero CPU; while playing, the window redraws at 60 Hz (spec §5.7).
- Config (spec §5.9):
  - fields: `version`, window position, double-size, always-on-top, volume, balance, time mode, visualizer mode, shuffle, repeat;
  - atomic writes, debounced 1 s, flushed on exit;
  - unknown fields ignored; a corrupt file renamed `config.toml.bak` with a marquee warning;
  - a position off every monitor resets onto the primary one.
- Errors show as marquee text for 3 s; an unreadable file advances to the next entry (spec §5.10).
- Driving `winrust-ui`, from the part 1 final review:
  - `UiEvent::MoveWindow` is an offset to add to the window's current position;
  - call `Interaction::cancel` on focus loss;
  - redraw when `pressed()` or `sliding()` changes, not only on events;
  - call `Vis::frame` only on the 60 Hz tick, keep the last frame while paused and none when stopped;
  - double-click detection is the app's job.
- `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings` and `cargo deny check` stay clean.
- Work on branch `m3-part2-app`. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Decisions fixed by this plan

These settle what the spec leaves open; each costs little to change later.

- **`Model::apply` takes the current `Instant`:** the fadeout, the paused-time blink and the marquee stay pure and testable. The spec's sketch has no time argument.
- **Transport follows Webamp `getNextTrackId`:**
  - previous and next start playing even when stopped;
  - past either end without repeat they stop;
  - ±10 jumps clamp to the ends;
  - shuffle picks any other entry, forever (a one-entry queue replays it).
- **C while stopped does nothing**, as the spec's "pause / resume" says (Webamp starts playing). **X while playing restarts the track** by reloading it, which also reconnects a stream.
- **Ctrl+V toggles "stop after current".** It takes the gapless track back with the new `Command::Unqueue`, and shows no indicator. If the gapless start already happened (the last ~200 ms of a file), the app sends Stop.
- **A queue whose entries all fail** stops after one round, with repeat or shuffle on too.
- **Held keys repeat only seeking and volume.** Toggles fire once per press.
- **Hotkey letters follow the keyboard layout** (Winamp's virtual keys). When the layout gives no Latin letter (Greek, macOS Option), the key's position decides. Numpad digits count only with Num Lock on; without it they are arrows.
- **Mouse wheel:** one volume step per notch; touchpads, 20 pixels per step.
- **Double-click:** two presses within 500 ms (Windows' default) and 4 pixels.
- **Folders** given on the command line or dropped expand to their audio files, searched recursively by extension (`aac flac m4a mp3 mp4 oga ogg wav`) and sorted by path, ignoring case. Files named directly are kept whatever their extension.
- **Defaults:** volume 75 (Webamp); the idle marquee shows `Winrust <version>`.
- **Window placement:**
  - the saved position counts as on screen when at least 32 pixels of the title bar's width lie fully inside one monitor;
  - otherwise, and on first run, the window is centred on the primary monitor;
  - it opens hidden until sized and placed.
- **Not saved:** shade mode and the EQ/PL lit states (the spec's field list).
- **Linux builds without Wayland support** (winit and softbuffer `x11` features only), on top of `with_x11()`; nothing new is needed at build time.
- **Clutter V** (Winamp's visualization menu) is inert until the menus arrive in M7, like O and I.
- **No audio device:** if the engine cannot start, the window still opens, shows the error, and the controls do nothing.
- **Stream backlog:** the decode thread decodes a stream only while 8 KiB wait in the pipe, or once the stream has ended.
- **`winrust --version`** prints the banner and exits.

### Task 1: Keep reporting while a stream stalls

M1 carry-forward (spec §5.6): while a stream read waits for the network, the decode thread is stuck inside it. Position and state events stop, and Pause waits, until data resumes or the read times out after 15 s. The fix lets the network thread count the bytes it has queued; the decode thread decodes only while enough are waiting.

**Files:**
- Modify: `crates/audio/src/stream.rs`, `crates/audio/src/engine.rs`
- Test: `crates/audio/src/stream.rs` (unit), `crates/audio/tests/engine_edges.rs`

**Interfaces:**
- Consumes: the M1 engine (`Worker`, `Active`, `open_source`) and `stream::open`.
- Produces:
  - `stream::Backlog` (`Clone`, `Default`), with `Backlog::ready(&self, want: usize) -> bool`;
  - the field `OpenStream::backlog: Backlog`;
  - no change to the engine's public API.

```rust
//! What plays next: the entries from the command line or a drop, the one playing, and the
//! one handed to the engine early for a gapless start. Pure; the model turns its answers into
//! engine commands. Order rules follow Webamp `getNextTrackId`; the playlist crate replaces
//! this in M4.

use winrust_audio::Source;

/// What the engine's queued track should become after a setting changed.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Requeue {
    /// Send this entry with `QueueNext`.
    Queue(usize),
    /// Send `Unqueue`.
    Unqueue,
    Keep,
}

#[derive(Clone, Debug)]
pub struct Queue {
    entries: Vec<Source>,
    current: Option<usize>,
    /// The entry handed to the engine with `QueueNext`.
    queued: Option<usize>,
    /// The engine reported that the queued entry cannot be opened.
    queued_failed: bool,
    /// `current` was loaded and has not started yet.
    awaiting_start: bool,
    /// The engine has a track loaded (playing, paused or starting).
    playing: bool,
    /// Entries that failed one after another; when every entry has, playback stops.
    failures: usize,
    pub shuffle: bool,
    pub repeat: bool,
    /// Stop when the current track ends (Ctrl+V).
    pub stop_after: bool,
    rng: u64,
}

impl Queue {
    /// `seed` drives the shuffle order.
    pub fn new(seed: u64) -> Self {
        Queue {
            entries: Vec::new(),
            current: None,
            queued: None,
            queued_failed: false,
            awaiting_start: false,
            playing: false,
            failures: 0,
            shuffle: false,
            repeat: false,
            stop_after: false,
            rng: seed | 1,
        }
    }

    pub fn len(&self) -> usize {
        self.entries.len()
    }

    pub fn is_empty(&self) -> bool {
        self.entries.is_empty()
    }

    pub fn entry(&self, index: usize) -> Option<&Source> {
        self.entries.get(index)
    }

    pub fn current(&self) -> Option<usize> {
        self.current
    }

    /// Replaces every entry; returns the first one, to load.
    pub fn replace(&mut self, entries: Vec<Source>) -> Option<usize> {
        self.entries = entries;
        self.current = None;
        self.stop();
        self.failures = 0;
        if self.entries.is_empty() {
            None
        } else {
            self.load(0)
        }
    }

    /// The entry to load for Play: the current one, else the first.
    pub fn restart(&mut self) -> Option<usize> {
        let index = self.current.or((!self.entries.is_empty()).then_some(0))?;
        self.failures = 0;
        self.load(index)
    }

    /// The entry `n` steps away (previous, next, ±10 jumps), to load; `None` past either end
    /// without repeat.
    pub fn step(&mut self, n: i32) -> Option<usize> {
        let index = match self.current {
            Some(from) => self.pick(from, n),
            None => (!self.entries.is_empty()).then_some(0),
        }?;
        self.failures = 0;
        self.load(index)
    }

    /// Playback stopped; the current entry stays for Play.
    pub fn stop(&mut self) {
        self.queued = None;
        self.queued_failed = false;
        self.awaiting_start = false;
        self.playing = false;
        self.stop_after = false;
    }

    /// A track became audible. Returns the entry to hand to the engine with `QueueNext`.
    pub fn on_started(&mut self, gapless: bool) -> Option<usize> {
        if gapless && let Some(q) = self.queued.take() {
            self.current = Some(q);
        }
        self.queued = None;
        self.queued_failed = false;
        self.awaiting_start = false;
        self.failures = 0;
        self.queue_next()
    }

    /// The engine reported an error; `is_source` tells whether a source is the one it names.
    /// Returns the entry to load instead.
    pub fn on_error(&mut self, is_source: impl Fn(&Source) -> bool) -> Option<usize> {
        if self.queued.is_some_and(|q| is_source(&self.entries[q])) {
            self.queued_failed = true;
            return None;
        }
        match self.current {
            Some(i) if self.awaiting_start && is_source(&self.entries[i]) => self.skip(i),
            _ => None,
        }
    }

    /// The engine stopped at the end of its last track. Returns the entry to load.
    pub fn on_ended(&mut self) -> Option<usize> {
        if self.stop_after {
            self.stop();
            return None;
        }
        match self.queued.take() {
            Some(q) if self.queued_failed => self.skip(q),
            // The engine finished before it saw the queued track: play it now.
            Some(q) => self.load(q),
            None => {
                self.stop();
                None
            }
        }
    }

    /// Shuffle, repeat or stop-after changed: what the engine's queued track becomes.
    pub fn requeue(&mut self) -> Requeue {
        if !self.playing || self.awaiting_start {
            return Requeue::Keep;
        }
        let before = self.queued;
        match self.queue_next() {
            Some(next) => Requeue::Queue(next),
            None if before.is_some() => Requeue::Unqueue,
            None => Requeue::Keep,
        }
    }

    fn queue_next(&mut self) -> Option<usize> {
        let current = self.current?;
        self.queued = if self.stop_after {
            None
        } else {
            self.pick(current, 1)
        };
        self.queued_failed = false;
        self.queued
    }

    /// Moves past an entry that cannot be opened, unless every entry has failed in a row.
    fn skip(&mut self, failed: usize) -> Option<usize> {
        self.failures += 1;
        let next = if self.failures < self.entries.len() {
            self.pick(failed, 1)
        } else {
            None
        };
        match next {
            Some(i) => self.load(i),
            None => {
                self.stop();
                None
            }
        }
    }

    fn load(&mut self, index: usize) -> Option<usize> {
        self.current = Some(index);
        self.queued = None;
        self.queued_failed = false;
        self.awaiting_start = true;
        self.playing = true;
        Some(index)
    }

    /// The entry `n` steps from `from` (Webamp `getNextTrackId`): shuffle picks any other
    /// entry; repeat wraps; otherwise `None` past either end, and jumps clamp.
    fn pick(&mut self, from: usize, n: i32) -> Option<usize> {
        let len = self.entries.len();
        if len == 0 {
            return None;
        }
        if self.shuffle {
            if len == 1 {
                return Some(0);
            }
            loop {
                let i = self.random(len);
                if i != from {
                    return Some(i);
                }
            }
        }
        let to = from as i64 + i64::from(n);
        if self.repeat {
            return Some(to.rem_euclid(len as i64) as usize);
        }
        if (from + 1 == len && n > 0) || (from == 0 && n < 0) {
            return None;
        }
        Some(to.clamp(0, len as i64 - 1) as usize)
    }

    /// xorshift64: plenty for a shuffle, and repeatable in tests.
    fn random(&mut self, below: usize) -> usize {
        self.rng ^= self.rng << 13;
        self.rng ^= self.rng >> 7;
        self.rng ^= self.rng << 17;
        (self.rng % below as u64) as usize
    }
}
```

```rust
//! Turns command-line arguments and dropped paths into sources. A folder stands for the
//! audio files inside it, in name order.

use std::ffi::OsString;
use std::path::PathBuf;
use winrust_audio::Source;

/// File extensions a folder is searched for (what the audio engine decodes).
pub const AUDIO_EXTENSIONS: [&str; 8] = ["aac", "flac", "m4a", "mp3", "mp4", "oga", "ogg", "wav"];

/// `winrust [file|folder|URL]...`
pub fn from_args(args: impl IntoIterator<Item = OsString>) -> Vec<Source> {
    let mut out = Vec::new();
    for arg in args {
        match arg.to_str().filter(|s| is_url(s)) {
            Some(url) => out.push(Source::Url(url.to_string())),
            None => expand(PathBuf::from(arg), &mut out),
        }
    }
    out
}

/// Files and folders dropped on the window.
pub fn from_paths(paths: Vec<PathBuf>) -> Vec<Source> {
    let mut out = Vec::new();
    for path in paths {
        expand(path, &mut out);
    }
    out
}

fn is_url(s: &str) -> bool {
    let lower = s.to_ascii_lowercase();
    ["http://", "https://", "icy://"]
        .iter()
        .any(|p| lower.starts_with(p))
}

/// A file as it is (a bad one is reported when it plays); a folder as the audio files in it
/// and its subfolders, sorted by path ignoring case. Unreadable folders add nothing.
fn expand(path: PathBuf, out: &mut Vec<Source>) {
    if !path.is_dir() {
        out.push(Source::File(path));
        return;
    }
    let mut files = Vec::new();
    let mut folders = vec![path];
    while let Some(folder) = folders.pop() {
        let Ok(entries) = std::fs::read_dir(&folder) else {
            continue;
        };
        for entry in entries.flatten() {
            let path = entry.path();
            match entry.file_type() {
                Ok(t) if t.is_dir() => folders.push(path),
                Ok(t) if t.is_file() && is_audio(&path) => files.push(path),
                _ => {}
            }
        }
    }
    files.sort_by_cached_key(|p| p.to_string_lossy().to_lowercase());
    out.extend(files.into_iter().map(Source::File));
}

fn is_audio(path: &std::path::Path) -> bool {
    path.extension()
        .and_then(|e| e.to_str())
        .is_some_and(|e| AUDIO_EXTENSIONS.contains(&e.to_ascii_lowercase().as_str()))
}
```

```rust
#![allow(dead_code)]

use std::path::PathBuf;
use std::time::{Duration, Instant};
use winrust_app::model::{Action, Control, Effect, Model};
use winrust_audio::{Command, EngineEvent, PlaybackState, Source, TrackInfo};

pub fn file(name: &str) -> Source {
    Source::File(PathBuf::from(format!("{name}.mp3")))
}

pub fn info(source: &Source, secs: u64) -> TrackInfo {
    TrackInfo {
        source: source.clone(),
        kbps: Some(128),
        sample_rate: 44_100,
        channels: 2,
        duration: Some(Duration::from_secs(secs)),
        seekable: true,
    }
}

pub fn commands(effects: &[Effect]) -> Vec<Command> {
    effects
        .iter()
        .filter_map(|e| match e {
            Effect::Engine(c) => Some(c.clone()),
            _ => None,
        })
        .collect()
}

/// A model plus the clock its actions see.
pub struct Harness {
    pub model: Model,
    pub now: Instant,
}

impl Harness {
    pub fn new() -> Self {
        Harness {
            model: Model::new(7),
            now: Instant::now(),
        }
    }

    /// `names` opened, the first one started and playing; tracks last `secs` seconds.
    pub fn playing(names: &[&str], secs: u64) -> Self {
        let mut h = Harness::new();
        h.apply(Action::Open(names.iter().map(|n| file(n)).collect()));
        h.started(names[0], secs, false);
        h.engine(EngineEvent::State(PlaybackState::Playing));
        h
    }

    pub fn apply(&mut self, action: Action) -> Vec<Effect> {
        self.model.apply(action, self.now)
    }

    pub fn control(&mut self, c: Control) -> Vec<Effect> {
        self.apply(Action::Control(c))
    }

    pub fn engine(&mut self, e: EngineEvent) -> Vec<Effect> {
        self.apply(Action::Engine(e))
    }

    pub fn started(&mut self, name: &str, secs: u64, gapless: bool) -> Vec<Effect> {
        self.engine(EngineEvent::TrackStarted {
            info: info(&file(name), secs),
            gapless,
        })
    }

    pub fn advance(&mut self, by: Duration) {
        self.now += by;
    }
}
```

```rust
//! The app's state and rules (umbrella spec §5.3): every input becomes an [`Action`];
//! [`Model::apply`] updates the state and returns the [`Effect`]s for the app to carry out.
//! Pure, so it is tested without a window or an audio device.

use crate::queue::{Queue, Requeue};
use std::time::{Duration, Instant};
use winrust_audio::{Command, EngineEvent, PlaybackState, Source, TrackInfo};
use winrust_ui::interaction::{Interaction, Pointer};
use winrust_ui::marquee::{self, Marquee};
use winrust_ui::view::TimeMode;
use winrust_ui::vis::VisMode;

/// A request from a button, a hotkey or the mouse wheel.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Control {
    Previous,
    /// Play; restart if playing; resume if paused.
    Play,
    /// Pause, or resume if paused.
    Pause,
    Stop,
    /// Stop with a 1 s fadeout (Shift+V).
    FadeStop,
    /// Stop when the current track ends (Ctrl+V); pressing again cancels it.
    StopAfterCurrent,
    Next,
    /// Jump this many entries (numpad 1 and 3: ±10).
    Jump(i32),
    /// Seek this many seconds from the current position.
    SeekBy(i32),
    /// Change the volume by this many percent.
    VolumeBy(i32),
    ToggleRepeat,
    ToggleShuffle,
    ToggleTimeMode,
    ToggleDoubleSize,
    ToggleAlwaysOnTop,
    ToggleShade,
    /// The EQ and playlist buttons only light up until their windows exist (M4, M5).
    ToggleEq,
    TogglePlaylist,
    ToggleEasterEgg,
    Minimize,
    Close,
}

#[derive(Clone, Debug, PartialEq)]
pub enum Action {
    /// Files or URLs from the command line or a drop: replace the queue and play.
    Open(Vec<Source>),
    Control(Control),
    /// The pointer, in 1× window coordinates.
    Pointer(Pointer),
    Engine(EngineEvent),
    Focus(bool),
    /// The window's new outer position, in physical pixels.
    Moved {
        x: i32,
        y: i32,
    },
    /// Show a message in the marquee for a few seconds.
    Message(String),
    /// Time passed: animations advance.
    Tick,
}

#[derive(Clone, Debug, PartialEq)]
pub enum Effect {
    Engine(Command),
    Redraw,
    /// A saved setting changed: write the config soon.
    SaveConfig,
    /// Move the window by this many 1× pixels.
    MoveWindow {
        dx: i32,
        dy: i32,
    },
    /// Shade or double-size changed the window's size.
    Resize,
    SetAlwaysOnTop(bool),
    Minimize,
    Exit,
}

/// The audible track, as the main window shows it.
#[derive(Clone, Debug, PartialEq)]
pub struct Track {
    pub title: String,
    pub kbps: Option<u32>,
    /// Sample rate in whole kHz.
    pub khz: u32,
    pub channels: u16,
    pub duration: Option<Duration>,
    pub seekable: bool,
}

pub struct Model {
    pub queue: Queue,
    /// As the engine last reported it.
    pub state: PlaybackState,
    pub elapsed: Duration,
    pub track: Option<Track>,
    /// 0..=100.
    pub volume: u8,
    /// -100..=100.
    pub balance: i8,
    pub time_mode: TimeMode,
    pub vis_mode: VisMode,
    pub eq: bool,
    pub playlist: bool,
    pub shade: bool,
    pub double_size: bool,
    pub always_on_top: bool,
    pub easter_egg: bool,
    pub focused: bool,
    /// The window's outer position, in physical pixels.
    pub position: Option<(i32, i32)>,
    pub interaction: Interaction,
    pub marquee: Marquee,
}

impl Model {
    /// `seed` drives the shuffle order.
    pub fn new(seed: u64) -> Self {
        let mut marquee = Marquee::new();
        marquee.set_text(&format!("Winrust {}", env!("CARGO_PKG_VERSION")));
        Model {
            queue: Queue::new(seed),
            state: PlaybackState::Stopped,
            elapsed: Duration::ZERO,
            track: None,
            volume: 75,
            balance: 0,
            time_mode: TimeMode::Elapsed,
            vis_mode: VisMode::Spectrum,
            eq: false,
            playlist: false,
            shade: false,
            double_size: false,
            always_on_top: false,
            easter_egg: false,
            focused: true,
            position: None,
            interaction: Interaction::new(),
            marquee,
        }
    }

    /// Commands that give a fresh engine the saved volume and balance.
    pub fn engine_settings(&self) -> Vec<Command> {
        vec![
            Command::SetVolume(self.volume),
            Command::SetBalance(f32::from(self.balance) / 100.0),
        ]
    }

    pub fn apply(&mut self, action: Action, now: Instant) -> Vec<Effect> {
        let _ = now;
        let mut fx = Vec::new();
        // Whether the window shows something new, beyond what `fx` already implies.
        let changed = match action {
            Action::Open(sources) => {
                if let Some(i) = self.queue.replace(sources) {
                    self.load(i, &mut fx);
                }
                false
            }
            Action::Control(c) => {
                self.control(c, &mut fx);
                false
            }
            Action::Engine(e) => {
                self.engine(e, &mut fx);
                true
            }
            Action::Message(text) => {
                self.marquee.show_message(&text);
                true
            }
            Action::Pointer(_) | Action::Focus(_) | Action::Moved { .. } | Action::Tick => false,
        };
        if (changed || !fx.is_empty()) && !fx.contains(&Effect::Redraw) {
            fx.push(Effect::Redraw);
        }
        fx
    }

    fn control(&mut self, c: Control, fx: &mut Vec<Effect>) {
        use PlaybackState::*;
        match c {
            Control::Play => match self.state {
                Paused => fx.push(Effect::Engine(Command::Play)),
                _ => {
                    if let Some(i) = self.queue.restart() {
                        self.load(i, fx);
                    }
                }
            },
            Control::Pause => match self.state {
                Playing | Buffering => fx.push(Effect::Engine(Command::Pause)),
                Paused => fx.push(Effect::Engine(Command::Play)),
                Stopped => {}
            },
            Control::Stop | Control::FadeStop => self.stop(fx),
            Control::StopAfterCurrent => {
                self.queue.stop_after = !self.queue.stop_after;
                self.requeue(fx);
            }
            Control::Previous => self.step(-1, fx),
            Control::Next => self.step(1, fx),
            Control::Jump(n) => self.step(n, fx),
            Control::SeekBy(secs) => {
                let Some(duration) = self
                    .track
                    .as_ref()
                    .filter(|t| t.seekable)
                    .and_then(|t| t.duration)
                else {
                    return;
                };
                if self.state == Stopped {
                    return;
                }
                let to = (self.elapsed.as_secs_f64() + f64::from(secs))
                    .clamp(0.0, duration.as_secs_f64());
                self.seek(Duration::from_secs_f64(to), fx);
            }
            Control::VolumeBy(d) => {
                self.set_volume((i32::from(self.volume) + d).clamp(0, 100) as u8, fx);
            }
            Control::ToggleRepeat => {
                self.queue.repeat = !self.queue.repeat;
                self.requeue(fx);
                fx.push(Effect::SaveConfig);
            }
            Control::ToggleShuffle => {
                self.queue.shuffle = !self.queue.shuffle;
                self.requeue(fx);
                fx.push(Effect::SaveConfig);
            }
            Control::ToggleTimeMode
            | Control::ToggleDoubleSize
            | Control::ToggleAlwaysOnTop
            | Control::ToggleShade
            | Control::ToggleEq
            | Control::TogglePlaylist
            | Control::ToggleEasterEgg
            | Control::Minimize
            | Control::Close => {}
        }
    }

    fn engine(&mut self, event: EngineEvent, fx: &mut Vec<Effect>) {
        match event {
            EngineEvent::State(state) => self.state = state,
            EngineEvent::Position(p) => self.elapsed = p,
            EngineEvent::TrackStarted { info, gapless } => {
                if gapless && self.queue.stop_after {
                    // Stop-after-current came too late to unqueue this track.
                    self.queue.stop();
                    fx.push(Effect::Engine(Command::Stop));
                    return;
                }
                self.elapsed = Duration::ZERO;
                self.track = Some(track(&info));
                if let Some(next) = self.queue.on_started(gapless) {
                    self.queue_next(next, fx);
                }
                self.update_title();
            }
            EngineEvent::Bitrate(kbps) => {
                if let Some(t) = &mut self.track {
                    t.kbps = Some(kbps);
                }
            }
            EngineEvent::StreamTitle(title) => {
                if let Some(t) = &mut self.track {
                    t.title = title;
                }
                self.update_title();
            }
            EngineEvent::TrackEnded => {
                if let Some(i) = self.queue.on_ended() {
                    self.load(i, fx);
                }
            }
            EngineEvent::Error { source, error } => {
                self.marquee.show_message(&error.to_string());
                if let Some(source) = source
                    && let Some(i) = self.queue.on_error(|s| *s == source)
                {
                    self.load(i, fx);
                }
            }
        }
    }

    fn load(&mut self, index: usize, fx: &mut Vec<Effect>) {
        let Some(source) = self.queue.entry(index).cloned() else {
            return;
        };
        self.marquee
            .set_text(&marquee::track_title(index + 1, &name(&source), None));
        fx.push(Effect::Engine(Command::Load(source)));
    }

    fn queue_next(&mut self, index: usize, fx: &mut Vec<Effect>) {
        if let Some(source) = self.queue.entry(index).cloned() {
            fx.push(Effect::Engine(Command::QueueNext(source)));
        }
    }

    fn requeue(&mut self, fx: &mut Vec<Effect>) {
        match self.queue.requeue() {
            Requeue::Queue(i) => self.queue_next(i, fx),
            Requeue::Unqueue => fx.push(Effect::Engine(Command::Unqueue)),
            Requeue::Keep => {}
        }
    }

    fn step(&mut self, n: i32, fx: &mut Vec<Effect>) {
        match self.queue.step(n) {
            Some(i) => self.load(i, fx),
            // Past either end without repeat: Webamp stops.
            None if self.state != PlaybackState::Stopped => self.stop(fx),
            None => {}
        }
    }

    fn stop(&mut self, fx: &mut Vec<Effect>) {
        self.queue.stop();
        fx.push(Effect::Engine(Command::Stop));
    }

    fn seek(&mut self, to: Duration, fx: &mut Vec<Effect>) {
        self.elapsed = to;
        fx.push(Effect::Engine(Command::Seek(to)));
    }

    fn set_volume(&mut self, volume: u8, fx: &mut Vec<Effect>) {
        if volume != self.volume {
            self.volume = volume;
            fx.push(Effect::Engine(Command::SetVolume(volume)));
            fx.push(Effect::SaveConfig);
        }
    }

    fn update_title(&mut self) {
        if let (Some(t), Some(i)) = (&self.track, self.queue.current()) {
            self.marquee
                .set_text(&marquee::track_title(i + 1, &t.title, t.duration));
        }
    }
}

fn track(info: &TrackInfo) -> Track {
    Track {
        title: name(&info.source),
        kbps: info.kbps,
        khz: (info.sample_rate + 500) / 1000,
        channels: info.channels,
        duration: info.duration,
        seekable: info.seekable,
    }
}

/// A file's name without its extension, or a stream's URL (until it sends a title).
fn name(source: &Source) -> String {
    match source {
        Source::File(path) => path
            .file_stem()
            .unwrap_or(path.as_os_str())
            .to_string_lossy()
            .into_owned(),
        Source::Url(url) => url.clone(),
    }
}
```

```rust
/// AZERTY Z key is Z); when the layout gives no Latin letter (Greek, or a macOS Option
/// combination) the key's position decides. Numpad digits count only with Num Lock on;
/// without it the numpad keys are arrows.
pub fn key(logical: &WinitKey, physical: PhysicalKey, location: KeyLocation) -> Key {
    match logical {
        WinitKey::Named(NamedKey::ArrowLeft) => return Key::Left,
        WinitKey::Named(NamedKey::ArrowRight) => return Key::Right,
        WinitKey::Named(NamedKey::ArrowUp) => return Key::Up,
        WinitKey::Named(NamedKey::ArrowDown) => return Key::Down,
        WinitKey::Named(NamedKey::Escape) => return Key::Escape,
        WinitKey::Character(s) => {
            let mut chars = s.chars();
            if let (Some(c), None) = (chars.next(), chars.next()) {
                if location == KeyLocation::Numpad
                    && let Some(d) = c.to_digit(10)
                {
                    return Key::Numpad(d as u8);
                }
                if c.is_ascii_alphabetic() {
                    return Key::Letter(c.to_ascii_lowercase());
                }
            }
        }
        _ => {}
    }
    match physical {
        PhysicalKey::Code(code) => LETTERS
            .iter()
            .find(|(k, _)| *k == code)
            .map_or(Key::Other, |(_, c)| Key::Letter(*c)),
        PhysicalKey::Unidentified(_) => Key::Other,
    }
}

    /// volume.
    pub fn press(&mut self, key: Key, mods: Mods, repeat: bool) -> Vec<Control> {

            .filter(|c| !repeat || matches!(c, Control::SeekBy(_) | Control::VolumeBy(_)))

/// Touchpads scroll in pixels: this many make one volume step.
const PIXELS_PER_STEP: f64 = 20.0;

/// The mouse wheel as volume steps: one per notch, fractions carried over.
#[derive(Clone, Debug, Default)]
pub struct Wheel {
    lines: f64,
    pixels: f64,
}

impl Wheel {
    pub fn steps(&mut self, delta: MouseScrollDelta) -> i32 {
        let (acc, per_step) = match delta {
            MouseScrollDelta::LineDelta(_, y) => {
                self.lines += f64::from(y);
                (&mut self.lines, 1.0)
            }
            MouseScrollDelta::PixelDelta(p) => {
                self.pixels += p.y;
                (&mut self.pixels, PIXELS_PER_STEP)
            }
        };
        let steps = (*acc / per_step).trunc();
        *acc -= steps * per_step;
        steps as i32
    }
}

/// Windows' default double-click time.
const DOUBLE_CLICK: Duration = Duration::from_millis(500);
/// How far (1× pixels) the second press may land from the first.
const DOUBLE_CLICK_SLOP: i32 = 4;

/// Spots the second press of a double-click (winit reports single presses only).
#[derive(Clone, Debug, Default)]
pub struct DoubleClick {
    last: Option<(Instant, i32, i32)>,
}

impl DoubleClick {
    pub fn press(&mut self, now: Instant, x: i32, y: i32) -> bool {
        let double = self.last.is_some_and(|(at, lx, ly)| {
            now.saturating_duration_since(at) <= DOUBLE_CLICK
                && (x - lx).abs() <= DOUBLE_CLICK_SLOP
                && (y - ly).abs() <= DOUBLE_CLICK_SLOP
        });
        self.last = (!double).then_some((now, x, y));
        double
    }
}
```

```rust
/// The config folder: `%APPDATA%\winrust`, `~/Library/Application Support/winrust` or
/// `~/.config/winrust` (umbrella spec §9.4).
pub fn dir() -> Option<PathBuf> {
    directories::BaseDirs::new().map(|d| d.config_dir().join("winrust"))
}

/// Reads `config.toml` from `dir`. A missing file gives the defaults. An unreadable or
/// invalid one is renamed `config.toml.bak` and gives the defaults, with a message saying so.
pub fn load(dir: &Path) -> (Config, Option<String>) {
    let path = dir.join(FILE);
    let text = match std::fs::read_to_string(&path) {
        Ok(text) => text,
        Err(e) if e.kind() == io::ErrorKind::NotFound => return (Config::default(), None),
        Err(_) => String::new(),
    };
    match toml::from_str(&text) {
        Ok(config) if !text.is_empty() => (config, None),
        _ => {
            let _ = std::fs::rename(&path, dir.join(BACKUP));
            let warning = "Settings reset: config.toml was unreadable".to_string();
            (Config::default(), Some(warning))
        }
    }
}

/// Writes `config.toml` into `dir`, creating the folder. The text goes to a temporary file
/// first and is renamed over the old one, so a crash never leaves half a file.
pub fn save(dir: &Path, config: &Config) -> io::Result<()> {
    std::fs::create_dir_all(dir)?;
    let text = toml::to_string(config).map_err(io::Error::other)?;
    let temp = dir.join(TEMP);
    std::fs::write(&temp, text)?;
    std::fs::rename(&temp, dir.join(FILE))
}

/// When to save: [`SAVE_AFTER`] past the last change.
#[derive(Clone, Debug, Default)]
pub struct Debounce {
    due: Option<Instant>,
}

impl Debounce {
    /// A setting changed.
    pub fn poke(&mut self, now: Instant) {
        self.due = Some(now + SAVE_AFTER);
    }

    pub fn due(&self) -> Option<Instant> {
        self.due
    }

    /// True once, when the save is due.
    pub fn take(&mut self, now: Instant) -> bool {
        if self.due.is_some_and(|due| now >= due) {
            self.due = None;
            return true;
        }
        false
    }

    /// True if a save is waiting at all (on exit).
    pub fn take_pending(&mut self) -> bool {
        self.due.take().is_some()
    }
}

/// A monitor's area, in physical pixels.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct Area {
    pub x: i32,
    pub y: i32,
    pub w: u32,
    pub h: u32,
}

/// How much of the title bar must show to count as on screen: its full height, this wide.
const MIN_VISIBLE: i64 = 32;

/// Where the main window opens: the saved position if enough of its title bar shows on a
/// monitor to drag it, else centred on the primary monitor (`None` without one: the OS
/// decides).
pub fn place(
    saved: Option<[i32; 2]>,
    size: (u32, u32),
    monitors: &[Area],
    primary: Option<Area>,
) -> Option<(i32, i32)> {
    if let Some([x, y]) = saved
        && monitors.iter().any(|m| title_bar_shows((x, y), size, m))
    {
        return Some((x, y));
    }
    let p = primary?;
    let centre = |start: i32, space: u32, len: u32| start + (space.saturating_sub(len) / 2) as i32;
    Some((centre(p.x, p.w, size.0), centre(p.y, p.h, size.1)))
}

fn title_bar_shows((x, y): (i32, i32), (w, h): (u32, u32), m: &Area) -> bool {
    let (x, y, mx, my) = (i64::from(x), i64::from(y), i64::from(m.x), i64::from(m.y));
    let bar = i64::from(h.min(14));
    let overlap = (x + i64::from(w)).min(mx + i64::from(m.w)) - x.max(mx);
    overlap >= MIN_VISIBLE && y >= my && y + bar <= my + i64::from(m.h)
}
```

```rust
//! Getting the 1× compositor image onto the screen: integer scaling (M3 spec §5.2) and the
//! pixel copy into the window's buffer.

use winrust_skin::Image;
use winrust_ui::layout::Mode;

/// Screen pixels per skin pixel: the OS scale factor rounded to a whole number (at least 1,
/// so pixels stay sharp), doubled in double-size mode.
pub fn scale(os_factor: f64, double_size: bool) -> u32 {
    let os = (os_factor.round() as u32).max(1);
    if double_size { os * 2 } else { os }
}

/// The window's size in physical pixels.
pub fn window_size(shade: bool, scale: u32) -> (u32, u32) {
    let mode = if shade { Mode::Shade } else { Mode::Normal };
    let (w, h) = mode.size();
    (w * scale, h * scale)
}

/// A physical pointer coordinate in 1× window pixels; positions left of or above the window
/// (while a drag holds the pointer) are negative.
pub fn to_1x(physical: f64, scale: u32) -> i32 {
    (physical / f64::from(scale.max(1))).floor() as i32
}

/// Copies `src` into a `width`-wide buffer, each pixel as a `scale`×`scale` block, in the
/// `0RGB` format windows take. Buffer pixels past the image are black.
pub fn upscale(src: &Image, scale: u32, dst: &mut [u32], width: u32) {
    let scale = scale.max(1);
    for (y, row) in dst.chunks_mut(width.max(1) as usize).enumerate() {
        let sy = y as u32 / scale;
        for (x, px) in row.iter_mut().enumerate() {
            let sx = x as u32 / scale;
            *px = if sx < src.width && sy < src.height {
                src.pixels[(sy * src.width + sx) as usize] & 0x00FF_FFFF
            } else {
                0
            };
        }
    }
}
```

```rust
//! Winrust: the skinned main window. `winrust_app::model` decides everything; this file
//! carries winit's events to it and its effects back out to the window, the engine and the

use std::ffi::OsString;

struct App {
    model: Model,
    /// Files and URLs from the command line, opened once the window exists.
    startup: Vec<Source>,
    /// `None` when no audio output could start; the window still opens and says why.
    engine: Option<Engine>,

    analyzer: Option<AnalyzerReader>,
    skin: Arc<Skin>,
    vis: Vis,

    win: Option<Win>,

    wake: Option<Instant>,
    keys: Hotkeys,
    mods: Mods,
    wheel: Wheel,
    clicks: DoubleClick,

}

impl App {
    fn new(proxy: EventLoopProxy<EngineEvent>, startup: Vec<Source>) -> Self {
        let now = Instant::now();
        let seed = SystemTime::now()
            .duration_since(UNIX_EPOCH)
            .map_or(1, |d| d.as_nanos() as u64);
        let mut model = Model::new(seed);
        let config_dir = config::dir();
        let (settings, warning) = config_dir.as_deref().map(config::load).unwrap_or_default();
        settings.apply(&mut model);
        if let Some(warning) = warning {
            model.apply(Action::Message(warning), now);
        }
        let (engine, analyzer) = match Engine::spawn(Box::new(CpalSink::new(None))) {
            Ok(mut engine) => {
                let analyzer = engine.take_analyzer();
                forward_events(&engine, proxy);
                for c in model.engine_settings() {
                    engine.handle().send(c);
                }
                (Some(engine), analyzer)
            }
            Err(e) => {
                model.apply(Action::Message(e.to_string()), now);
                (None, None)
            }
        };
        App {
            handle: engine.as_ref().map(Engine::handle),
            model,
            startup,
            engine,
            analyzer,
            skin: Skin::base(),
            vis: Vis::new(VisSettings::default()),
            vis_frame: None,
            win: None,
            os_scale: 1.0,
            config_dir,
            save: Debounce::default(),
            wake: None,
            keys: Hotkeys::new(),
            mods: Mods::default(),
            wheel: Wheel::default(),
            clicks: DoubleClick::default(),
            cursor: (0, 0),
            dropped: Vec::new(),
        }
    }

    fn scale(&self) -> u32 {
        present::scale(self.os_scale, self.model.double_size)
    }

    fn size(&self) -> (u32, u32) {
        present::window_size(self.model.shade, self.scale())
    }

    fn open_window(&mut self, el: &ActiveEventLoop) -> Result<(), String> {
        let level = if self.model.always_on_top {
            WindowLevel::AlwaysOnTop
        } else {
            WindowLevel::Normal
        };
        let attributes = Window::default_attributes()
            .with_title("Winrust")
            .with_decorations(false)
            .with_resizable(false)
            .with_visible(false)
            .with_window_level(level);
        let window = Rc::new(el.create_window(attributes).map_err(|e| e.to_string())?);
        self.os_scale = window.scale_factor();
        let (w, h) = self.size();
        let _ = window.request_inner_size(PhysicalSize::new(w, h));
        let monitors: Vec<Area> = el.available_monitors().map(|m| area(&m)).collect();
        let primary = el.primary_monitor().map(|m| area(&m));
        let saved = self.model.position.map(|(x, y)| [x, y]);
        if let Some((x, y)) = config::place(saved, (w, h), &monitors, primary) {
            window.set_outer_position(PhysicalPosition::new(x, y));
        }
        let context = softbuffer::Context::new(window.clone()).map_err(|e| e.to_string())?;
        let surface =
            softbuffer::Surface::new(&context, window.clone()).map_err(|e| e.to_string())?;
        window.set_visible(true);
        window.request_redraw();
        self.win = Some(Win {
            window,
            surface,
            scale: self.scale(),
        });
        Ok(())
    }

    fn act(&mut self, el: &ActiveEventLoop, action: Action) {
        let now = Instant::now();
        for effect in self.model.apply(action, now) {
            self.run(el, effect, now);
        }
    }

    fn run(&mut self, el: &ActiveEventLoop, effect: Effect, now: Instant) {
        match effect {
            Effect::Engine(command) => self.send(command),
            Effect::Redraw => self.redraw(),
            Effect::SaveConfig => self.save.poke(now),
            Effect::MoveWindow { dx, dy } => {
                if let Some(win) = &self.win
                    && let Ok(p) = win.window.outer_position()
                {
                    let s = win.scale as i32;
                    win.window
                        .set_outer_position(PhysicalPosition::new(p.x + dx * s, p.y + dy * s));
                }
            }
            Effect::Resize => self.resize(),
            Effect::SetAlwaysOnTop(on) => {
                if let Some(win) = &self.win {
                    win.window.set_window_level(if on {
                        WindowLevel::AlwaysOnTop
                    } else {
                        WindowLevel::Normal
                    });
                }
            }
            Effect::Minimize => {
                if let Some(win) = &self.win {
                    win.window.set_minimized(true);
                }
            }
            Effect::Exit => el.exit(),
        }
    }

    fn send(&self, command: Command) {
        if let Some(handle) = &self.handle {
            handle.send(command);
        }
    }

    fn redraw(&self) {
        if let Some(win) = &self.win {
            win.window.request_redraw();
        }
    }

    /// Fits the window to the scale, shade and double-size settings.
    fn resize(&mut self) {
        let scale = self.scale();
        let (w, h) = self.size();
        if let Some(win) = &mut self.win {
            win.scale = scale;
            let _ = win.window.request_inner_size(PhysicalSize::new(w, h));
            win.window.request_redraw();
        }
    }

    fn draw(&mut self) {
        let Some(win) = &mut self.win else {
            return;
        };
        let size = win.window.inner_size();
        let (Some(w), Some(h)) = (NonZeroU32::new(size.width), NonZeroU32::new(size.height)) else {
            return;
        };
        let mut view = self.model.view(Instant::now());
        // A frame drawn for the other mode (shade toggled while paused) does not fit.
        let fits = if self.model.shade { (38, 5) } else { (76, 16) };
        view.vis = self
            .vis_frame
            .clone()
            .filter(|f| (f.width, f.height) == fits);
        let image = winrust_ui::draw::render(&self.skin, &view, &self.model.interaction);
        if win.surface.resize(w, h).is_err() {
            return;
        }
        if let Ok(mut buffer) = win.surface.buffer_mut() {
            present::upscale(&image, win.scale, &mut buffer, size.width);
            let _ = buffer.present();
        }
    }

    /// The visualizer advances once per frame while playing, keeps its last frame while
    /// paused and goes blank when stopped.
    fn update_vis(&mut self) {
        match self.model.state {
            PlaybackState::Playing | PlaybackState::Buffering => {
                if let Some(analyzer) = &mut self.analyzer {
                    self.vis.settings.mode = self.model.vis_mode;
                    let scope = analyzer.read();
                    self.vis_frame = self.vis.frame(
                        &scope.left,
                        &scope.right,
                        &self.skin.vis_colors,
                        self.model.shade,
                    );
                }
            }
            PlaybackState::Paused => {}
            PlaybackState::Stopped => self.vis_frame = None,
        }
    }

    fn save_config(&mut self) {
        let Some(dir) = &self.config_dir else {
            return;
        };
        if let Err(e) = config::save(dir, &Config::from_model(&self.model)) {
            let message = format!("Cannot save settings: {e}");
            eprintln!("winrust: {message}");
            self.model.apply(Action::Message(message), Instant::now());
            self.redraw();
        }
    }
}

impl ApplicationHandler<EngineEvent> for App {
    fn resumed(&mut self, el: &ActiveEventLoop) {
        if self.win.is_some() {
            return;
        }
        if let Err(e) = self.open_window(el) {
            eprintln!("winrust: cannot open the window: {e}");
            el.exit();
            return;
        }
        let startup = std::mem::take(&mut self.startup);
        if !startup.is_empty() {
            self.act(el, Action::Open(startup));
        }
    }

    fn user_event(&mut self, el: &ActiveEventLoop, event: EngineEvent) {
        self.act(el, Action::Engine(event));
    }

    fn window_event(&mut self, el: &ActiveEventLoop, _: WindowId, event: WindowEvent) {
        match event {
            WindowEvent::CloseRequested => self.act(el, Action::Control(Control::Close)),
            WindowEvent::RedrawRequested => self.draw(),
            WindowEvent::Focused(focused) => self.act(el, Action::Focus(focused)),
            WindowEvent::Moved(p) => self.act(el, Action::Moved { x: p.x, y: p.y }),
            WindowEvent::ScaleFactorChanged {
                scale_factor,
                mut inner_size_writer,
            } => {
                self.os_scale = scale_factor;
                let (w, h) = self.size();
                let _ = inner_size_writer.request_inner_size(PhysicalSize::new(w, h));
                let scale = self.scale();
                if let Some(win) = &mut self.win {
                    win.scale = scale;
                }
                self.redraw();
            }
            WindowEvent::CursorMoved { position, .. } => {
                let s = self.win.as_ref().map_or(1, |w| w.scale);
                self.cursor = (present::to_1x(position.x, s), present::to_1x(position.y, s));
                let (x, y) = self.cursor;
                self.act(el, Action::Pointer(Pointer::Move { x, y }));
            }
            WindowEvent::MouseInput {
                state,
                button: MouseButton::Left,
                ..
            } => {
                let (x, y) = self.cursor;
                let pointer = match state {
                    ElementState::Pressed => Pointer::Down {
                        x,
                        y,
                        double: self.clicks.press(Instant::now(), x, y),
                    },
                    ElementState::Released => Pointer::Up { x, y },
                };
                self.act(el, Action::Pointer(pointer));
            }
            WindowEvent::MouseWheel { delta, .. } => {
                let steps = self.wheel.steps(delta);
                if steps != 0 {
                    self.act(el, Action::Control(Control::VolumeBy(steps)));
                }
            }
            WindowEvent::ModifiersChanged(m) => {
                let s = m.state();
                self.mods = Mods {
                    ctrl: s.control_key(),
                    alt: s.alt_key(),
                    shift: s.shift_key(),
                };
            }
            WindowEvent::KeyboardInput {
                event,
                is_synthetic: false,
                ..
            } if event.state == ElementState::Pressed => {
                let key = input::key(&event.logical_key, event.physical_key, event.location);
                for control in self.keys.press(key, self.mods, event.repeat) {
                    self.act(el, Action::Control(control));
                }
            }
            WindowEvent::DroppedFile(path) => self.dropped.push(path),
            _ => {}
        }
    }

    fn about_to_wait(&mut self, el: &ActiveEventLoop) {
        if !self.dropped.is_empty() {
            let paths = std::mem::take(&mut self.dropped);
            self.act(el, Action::Open(sources::from_paths(paths)));
        }
        let now = Instant::now();
        let due = self.wake.is_some_and(|t| now >= t);
        if due {
            self.act(el, Action::Tick);
            self.update_vis();
        }
        // Keep a pending wake unless the model now wants an earlier one, so a stream of
        // input events cannot postpone the animation.
        let wanted = self.model.next_wake(now);
        self.wake = match (self.wake, wanted) {
            (Some(pending), Some(w)) if !due => Some(pending.min(w)),
            _ => wanted,
        };
        if self.save.take(now) {
            self.save_config();
        }
        let next = self.wake.into_iter().chain(self.save.due()).min();
        el.set_control_flow(next.map_or(ControlFlow::Wait, ControlFlow::WaitUntil));
    }

    fn exiting(&mut self, _: &ActiveEventLoop) {
        if self.save.take_pending() {
            self.save_config();
        }
        // Dropping the engine stops playback before the window goes.
        self.engine.take();
    }
}

/// Engine events wake the event loop from a helper thread.
fn forward_events(engine: &Engine, proxy: EventLoopProxy<EngineEvent>) {
    let events = engine.events().clone();
    let _ = std::thread::Builder::new()
        .name("winrust-events".into())
        .spawn(move || {
            for event in events.iter() {
                if proxy.send_event(event).is_err() {
                    break;
                }
            }
        });
}

fn area(m: &MonitorHandle) -> Area {
    let (p, s) = (m.position(), m.size());
    Area {
        x: p.x,
        y: p.y,
        w: s.width,
        h: s.height,
    }
}
```
