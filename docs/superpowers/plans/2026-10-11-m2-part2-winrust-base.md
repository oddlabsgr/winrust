# M2 Part 2: Winrust Base Skin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate Winrust Base, the original default skin, from drawing code (`cargo xtask gen-skin`), commit its files under `assets/skin/`, and make it the built-in fallback skin of `winrust-skin`.

**Architecture:**
- **Where the generator lives:** a new library half of `xtask` (`xtask/src/lib.rs`, module `gen_skin`). It draws every sprite of the 15 sheets at its rectangle from `winrust-skin`'s sprite table, using simple primitives, an original 4×5 pixel font and shape-based icons.
- **What it writes:** 24-bit BMPs plus `pledit.txt` and `viscolor.txt`.
- **How the skin crate uses it:** `crates/skin` embeds these files and builds the base skin from them with `Skin::complete`, replacing the debug skin as the fallback.
- **Drift check:** a test regenerates the skin and compares it with the committed files on all three CI platforms.

**Tech Stack:** Rust 2024; `winrust-skin` (sprite table, `Image`, `bmp::encode24`/`decode`, parsers) as `xtask`'s only dependency; no new external crates.

**Spec:** `docs/superpowers/specs/2026-10-10-winrust-design.md`: §4 (no Nullsoft assets), §7.3 (fallback to the base skin), §7.6 (Winrust Base generated by `cargo xtask gen-skin` into `assets/skin/`, reproducible), §11 (golden tests), §12.3 (M2: golden tests pass).

**Scope:** M2 part 2 of 2. Part 1 (the skin engine) is merged.

## Decisions fixed by this plan

- **Look** (approved by the user on 2026-10-11 from a rendered preview):
  - Gunmetal body with bevels.
  - Black LCDs with green (`#00E000`) digits and text.
  - Rust (`#B7410E`) and copper (`#E07B39`) accents on active title bars, slider knobs and pressed icons; inactive title bars turn grey.
  - Colours are in `palette.rs`.
- **Original art only:** every pixel is drawn by code. That includes an original seven-segment clock and an original 4×5 font (capitals only, like the LCD). No Nullsoft art is used (§4).
- **Easter-egg title bar:** reads "NO LLAMAS WERE HARMED".
- **Playlist colours (`pledit.txt`):**
  - Normal `#00E000`, Current `#FFFFFF`, NormalBG `#000000`.
  - SelectedBG `#6B2A12` (dark rust, instead of Winamp's blue).
  - Font Arial.
- **Visualization colours (`viscolor.txt`):** the classic palette (`viscolor::DEFAULT_COLORS`).
- **Winamp quirks drawn into the art:**
  - The time display's colon is in `main.bmp` (Winamp draws only the digits).
  - `numbers.bmp`'s minus sign is row 6 of the `2`, and its blank is row 6 of the `1`.
  - The equalizer's shade button is part of both EQ title bars, because Webamp reads `EQ_MAXIMIZE_BUTTON_ACTIVE_FALLBACK` from there.
  - Only the first 3 columns of the work indicators show.
- **Output files:**
  - Each sheet is written at its canonical size (`Sheet::size()`), as a 24-bit BMP with a lower-case name.
  - Text files use LF line endings, matching `.gitattributes` (`eol=lf`), so the committed bytes equal the generator's output on every platform.
- **`xtask` gains a library target and a `winrust-skin` dependency:**
  - It is no longer dependency-free.
  - Reason: the generator must draw at the sprite table's rectangles, and encode with the same BMP code the loader decodes.
  - Cost: a slower first `cargo xtask` build.
- **How the base skin is built:** it is embedded with `include_bytes!` and decoded on first use through `Skin::complete`. It is never built through the loader, because the loader itself falls back to `Skin::base()`.

## Global Constraints

- Edition 2024; package metadata from `[workspace.package]`; license `MIT OR Apache-2.0`.
- No Nullsoft or third-party skin art in the repository (§4); Winrust Base is drawn entirely by code (§7.6).
- `crates/skin` stays free of windowing and OS dependencies (§5.1).

    }

//! Drawing helpers on top of `winrust_skin::Image`.

use super::font;
use super::palette::*;
use winrust_skin::{Image, Rect};

pub fn rect(x: u32, y: u32, w: u32, h: u32) -> Rect {
    Rect::new(x, y, w, h)
}

/// Linear blend of two colours, `t` in 0..=1.
pub fn mix(a: u32, b: u32, t: f32) -> u32 {
    let ch = |shift: u32| {
        let ca = ((a >> shift) & 0xFF) as f32;
        let cb = ((b >> shift) & 0xFF) as f32;
        ((ca + (cb - ca) * t).round() as u32) << shift
    };
    0xFF00_0000 | ch(16) | ch(8) | ch(0)
}

pub fn hline(img: &mut Image, x: u32, y: u32, w: u32, c: u32) {
    img.fill_rect(rect(x, y, w, 1), c);
}

pub fn vline(img: &mut Image, x: u32, y: u32, h: u32, c: u32) {
    img.fill_rect(rect(x, y, 1, h), c);
}

/// Vertical gradient from `top` to `bottom`.
pub fn vgradient(img: &mut Image, r: Rect, top: u32, bottom: u32) {
    for dy in 0..r.h {
        let t = if r.h > 1 {
            dy as f32 / (r.h - 1) as f32
        } else {
            0.0
        };
        hline(img, r.x, r.y + dy, r.w, mix(top, bottom, t));
    }
}

/// One-pixel frame: `tl` on the top and left edges, `br` on the bottom and right.
pub fn frame(img: &mut Image, r: Rect, tl: u32, br: u32) {
    if r.w == 0 || r.h == 0 {
        return;
    }
    hline(img, r.x, r.y, r.w, tl);
    vline(img, r.x, r.y, r.h, tl);
    hline(img, r.x, r.y + r.h - 1, r.w, br);
    vline(img, r.x + r.w - 1, r.y, r.h, br);
}

pub fn inset(r: Rect, by: u32) -> Rect {
    rect(
        r.x + by,
        r.y + by,
        r.w.saturating_sub(2 * by),
        r.h.saturating_sub(2 * by),
    )
}

/// A raised metal surface: gradient face with a light top-left and dark bottom-right edge.
pub fn raised(img: &mut Image, r: Rect) {
    vgradient(img, r, FACE_TOP, FACE_BOTTOM);
    frame(img, r, BEVEL_LIGHT, BEVEL_DARK);
}

/// The same surface pushed in.
pub fn pressed(img: &mut Image, r: Rect) {
    vgradient(img, r, FACE_PRESSED_TOP, FACE_PRESSED_BOTTOM);
    frame(img, r, BEVEL_DARK, BEVEL_LIGHT);
}

/// A recessed black display with a dark outer edge.
pub fn lcd(img: &mut Image, r: Rect) {
    img.fill_rect(r, LCD_BG);
    frame(img, r, SHADOW, BEVEL_LIGHT);
}

/// A sunken groove (slider track).
pub fn groove(img: &mut Image, r: Rect) {
    img.fill_rect(r, GROOVE);
    frame(img, r, SHADOW, BEVEL_LIGHT);
}

/// Text in the 4×5 font; returns the width drawn.
pub fn text(img: &mut Image, x: u32, y: u32, s: &str, c: u32) -> u32 {
    let mut cx = x;
    for ch in s.chars() {
        let g = font::glyph(ch);
        for (row, bits) in g.rows.iter().enumerate() {
            for (col, b) in bits.bytes().enumerate() {
                if b == b'#' {
                    img.set(cx + col as u32, y + row as u32, c);
                }
            }
        }
        cx += g.width + 1;
    }
    cx.saturating_sub(x + 1)
}

pub fn text_width(s: &str) -> u32 {
    let w: u32 = s.chars().map(|c| font::glyph(c).width + 1).sum();
    w.saturating_sub(1)
}

/// Text centred horizontally in `r`, vertically at `r.y + (r.h - 5) / 2`.
pub fn text_centered(img: &mut Image, r: Rect, s: &str, c: u32) {
    let w = text_width(s);
    let x = r.x + r.w.saturating_sub(w) / 2;
    let y = r.y + r.h.saturating_sub(5) / 2;
    text(img, x, y, s, c);
}

/// Text with a one-pixel dark shadow below-right, for labels on metal.
pub fn label(img: &mut Image, x: u32, y: u32, s: &str, c: u32) {
    text(img, x + 1, y + 1, s, SHADOW);
    text(img, x, y, s, c);
}

pub fn label_centered(img: &mut Image, r: Rect, s: &str, c: u32) {
    let w = text_width(s);
    let x = r.x + r.w.saturating_sub(w) / 2;
    let y = r.y + r.h.saturating_sub(5) / 2;
    label(img, x, y, s, c);
}

/// Draws a small bitmap given as rows of `#` (colour `c`) and `.` (left alone).
pub fn bitmap(img: &mut Image, x: u32, y: u32, rows: &[&str], c: u32) {
    for (dy, row) in rows.iter().enumerate() {
        for (dx, b) in row.bytes().enumerate() {
            if b == b'#' {
                img.set(x + dx as u32, y + dy as u32, c);
            }
        }
    }
}

/// `bitmap` centred in `r`.
pub fn bitmap_centered(img: &mut Image, r: Rect, rows: &[&str], c: u32) {
    let w = rows.iter().map(|s| s.len()).max().unwrap_or(0) as u32;
    let h = rows.len() as u32;
    bitmap(
        img,
        r.x + r.w.saturating_sub(w) / 2,
        r.y + r.h.saturating_sub(h) / 2,
        rows,
        c,
    );
}

//! Winrust Base pixel font: glyphs up to 4×5, drawn into `text.bmp`'s 5×6 cells and used
//! for labels. Original design; letters are capitals only (the LCD shows text in capitals).

pub struct Glyph {
    pub width: u32,
    pub rows: [&'static str; 5],
}

const fn g(rows: [&'static str; 5]) -> Glyph {
    let mut width = 0;
    let mut i = 0;
    while i < 5 {
        if rows[i].len() > width {
            width = rows[i].len();
        }
        i += 1;
    }
    Glyph {
        width: width as u32,
        rows,
    }
}

/// A right-pointing triangle `h` pixels tall (odd), `(h + 1) / 2` wide, at (x, y).
pub fn tri_right(img: &mut Image, x: u32, y: u32, h: u32, c: u32) {
    for i in 0..h {
        let w = i.min(h - 1 - i) + 1;
        img.fill_rect(rect(x, y + i, w, 1), c);
    }
}

pub fn tri_left(img: &mut Image, x: u32, y: u32, h: u32, c: u32) {
    let full = h.div_ceil(2);
    for i in 0..h {
        let w = i.min(h - 1 - i) + 1;
        img.fill_rect(rect(x + full - w, y + i, w, 1), c);
    }
}

/// An upward triangle `w` pixels wide (odd), `(w + 1) / 2` tall.
pub fn tri_up(img: &mut Image, x: u32, y: u32, w: u32, c: u32) {
    let h = w.div_ceil(2);
    for i in 0..h {
        img.fill_rect(rect(x + h - 1 - i, y + i, 2 * i + 1, 1), c);
    }
}

pub fn tri_down(img: &mut Image, x: u32, y: u32, w: u32, c: u32) {
    let h = w.div_ceil(2);
    for i in 0..h {
        img.fill_rect(rect(x + i, y + i, w - 2 * i, 1), c);
    }
}

/// Transport icons, drawn centred in an area by [`transport`]; `size` is 7 for buttons and
/// 5 for mini buttons.
#[derive(Clone, Copy)]
pub enum Transport {
    Previous,
    Play,
    Pause,
    Stop,
    Next,
    Eject,
}

pub fn transport(img: &mut Image, kind: Transport, area: Rect, size: u32, c: u32) {
    let Rect { x, y, w, h } = area;
    let tri_w = size.div_ceil(2);
    let (iw, ih) = match kind {
        Transport::Previous | Transport::Next => (1 + 2 * tri_w, size),
        Transport::Play => (tri_w, size),
        Transport::Pause => (if size >= 7 { 6 } else { 4 }, size),
        Transport::Stop => (size, size),
        Transport::Eject => (size, tri_w + 2),
    };
    let ox = x + w.saturating_sub(iw) / 2;
    let oy = y + h.saturating_sub(ih) / 2;
    match kind {
        Transport::Play => tri_right(img, ox, oy, size, c),
        Transport::Previous => {
            img.fill_rect(rect(ox, oy, 1, size), c);
            tri_left(img, ox + 1, oy, size, c);
            tri_left(img, ox + 1 + tri_w, oy, size, c);
        }
        Transport::Next => {
            tri_right(img, ox, oy, size, c);
            tri_right(img, ox + tri_w, oy, size, c);
            img.fill_rect(rect(ox + 2 * tri_w, oy, 1, size), c);
        }
        Transport::Pause => {
            let bar = if size >= 7 { 2 } else { 1 };
            img.fill_rect(rect(ox, oy, bar, size), c);
            img.fill_rect(rect(ox + iw - bar, oy, bar, size), c);
        }
        Transport::Stop => img.fill_rect(rect(ox, oy, size, size), c),
        Transport::Eject => {
            tri_up(img, ox, oy, size, c);
            img.fill_rect(rect(ox, oy + tri_w + 1, size, 1), c);
        }
    }
}

/// Seven-segment digit in a 9×13 cell: 2-pixel bars and strokes, 1-pixel middle bar on
/// row 6 (Winamp reads the minus sign from that row of the `2`).
fn digit(img: &mut Image, x: u32, y: u32, d: Option<u8>, c: u32) {
    // Segments: a top, b upper right, c lower right, d bottom, e lower left, f upper left, g middle.
    let on: [bool; 7] = match d {
        Some(0) => [true, true, true, true, true, true, false],
        Some(1) => [false, true, true, false, false, false, false],
        Some(2) => [true, true, false, true, true, false, true],
        Some(3) => [true, true, true, true, false, false, true],
        Some(4) => [false, true, true, false, false, true, true],
        Some(5) => [true, false, true, true, false, true, true],
        Some(6) => [true, false, true, true, true, true, true],
        Some(7) => [true, true, true, false, false, false, false],
        Some(8) => [true; 7],
        Some(9) => [true, true, true, true, false, true, true],
        Some(_) => [false; 7],
        None => [false, false, false, false, false, false, true],
    };
    let seg = [
        rect(2, 0, 5, 2),
        rect(7, 2, 2, 4),
        rect(7, 7, 2, 4),
        rect(2, 11, 5, 2),
        rect(0, 7, 2, 4),
        rect(0, 2, 2, 4),
        rect(2, 6, 5, 1),
    ];
    for (lit, s) in on.iter().zip(seg) {
        if *lit {
            img.fill_rect(rect(x + s.x, y + s.y, s.w, s.h), c);
        }
    }
}

fn level_frames(img: &mut Image, area: Rect, centred: bool) {
    for i in 0..28u32 {
        let f = rect(area.x, area.y + 15 * i, area.w, 13);
        groove(img, f);
        let inner_w = f.w - 4;
        let fill = (inner_w * i).div_ceil(27).max(2);
        let c = level(i, 27);
        if centred {
            let x = f.x + 2 + (inner_w - fill) / 2;
            img.fill_rect(rect(x, f.y + 4, fill, 5), c);
        } else {
            img.fill_rect(rect(f.x + 2, f.y + 4, fill, 5), c);
        }
    }
}

fn toggle(img: &mut Image, b: Rect, down: bool, on: bool, draw: impl Fn(&mut Image, Rect, u32)) {

}

/// A push button: raised or pressed face; the icon shifts one pixel when pressed.
pub fn button(img: &mut Image, b: Rect, down: bool, icon: impl FnOnce(&mut Image, Rect, u32)) {
    if down {
        pressed(img, b);
        icon(img, rect(b.x + 1, b.y + 1, b.w, b.h), COPPER);
    } else {
        raised(img, b);
        icon(img, b, INK);

pub fn knob(img: &mut Image, b: Rect, active: bool, vertical_grip: bool) {
    if active {
        vgradient(img, b, COPPER, RUST);
        frame(img, b, COPPER, RUST_DARK);
    } else {
        raised(img, b);
    }
    let grip = if active { RUST_DARK } else { RUST };
    if vertical_grip {
        let cx = b.x + b.w / 2;
        for dx in [0u32, 2, 4] {
            vline(img, cx - 2 + dx, b.y + 3, b.h.saturating_sub(6), grip);
        }
    } else {
        let cy = b.y + b.h / 2;
        hline(img, b.x + 3, cy, b.w.saturating_sub(6), grip);
    }
}

pub fn title_stripes(img: &mut Image, x: u32, y: u32, w: u32, active: bool) {
    let (c, dark) = if active {
        (RUST, RUST_DARK)
    } else {
        (STRIPE_IDLE, STRIPE_IDLE_DARK)
    };
    for row in [0, 2, 4] {
        hline(img, x, y + row, w, c);
        hline(img, x, y + row + 1, w, dark);
    }
}

/// A 14-pixel title bar with the title centred between stripes.
pub fn title_bar(
    img: &mut Image,
    b: Rect,
    title: &str,
    active: bool,
    stripes_from: u32,
    stripes_to: u32,
) {
    vgradient(img, b, BODY_TOP, BODY_BOTTOM);
    frame(img, b, BEVEL_LIGHT, BEVEL_DARK);
    let w = text_width(title);
    let tx = b.x + (b.w - w) / 2;
    title_stripes(
        img,
        b.x + stripes_from,
        b.y + 4,
        tx - 4 - (b.x + stripes_from),
        active,
    );
    title_stripes(
        img,
        tx + w + 5,
        b.y + 4,
        b.x + stripes_to - (tx + w + 5),
        active,
    );
    label(
        img,
        tx,
        b.y + 4,
        title,
        if active { COPPER } else { INK_DIM },
    );
}

//! Generator of Winrust Base, the default skin (`cargo xtask gen-skin`, spec §7.6): original
//! pixel art drawn by code. Its output is committed under `assets/skin/`.

pub mod draw;
pub mod font;
pub mod icons;
pub mod palette;
pub mod sheets;

use std::path::Path;
use winrust_skin::{Sheet, bmp, viscolor};

/// Winrust Base's playlist colours.
pub const PLEDIT: &str =
    "[Text]\nNormal=#00E000\nCurrent=#FFFFFF\nNormalBG=#000000\nSelectedBG=#6B2A12\nFont=Arial\n";

/// The classic visualization colours, one `r,g,b` line each.
pub fn viscolor_txt() -> String {
    let mut out = String::new();
    for (i, c) in viscolor::DEFAULT_COLORS.iter().enumerate() {
        let what = match i {
            0 => "background",
            1 => "grid dots",
            2..=17 => "spectrum, top to bottom",
            18..=22 => "oscilloscope",
            _ => "peak dots",
        };
        let [_, r, g, b] = c.to_be_bytes();
        out.push_str(&format!("{r},{g},{b}, // {what}\n"));
    }
    out
}

/// Every file of the skin, by name: one BMP per sheet, `pledit.txt` and `viscolor.txt`.
pub fn files() -> Vec<(String, Vec<u8>)> {
    let mut out: Vec<(String, Vec<u8>)> = Sheet::ALL
        .iter()
        .zip(sheets::all())
        .map(|(sheet, image)| (format!("{}.bmp", sheet.stem()), bmp::encode24(&image)))
        .collect();
    out.push(("pledit.txt".into(), PLEDIT.as_bytes().to_vec()));
    out.push(("viscolor.txt".into(), viscolor_txt().into_bytes()));
    out
}

/// Writes the skin into `dir`; returns the number of files.
pub fn write(dir: &Path) -> std::io::Result<usize> {
    std::fs::create_dir_all(dir)?;
    let files = files();
    for (name, data) in &files {
        std::fs::write(dir.join(name), data)?;
    }
    Ok(files.len())
}

//! Developer tasks: `cargo xtask <task>`. The generators live in the library half (`lib.rs`)
//! so they can be tested.

use std::path::{Path, PathBuf};
use std::process::{Command, ExitCode};

const HELP: &str = "\
Usage: cargo xtask <task>

Tasks:
  help           Show this message
  gen-fixtures   Regenerate audio test fixtures (needs ffmpeg on PATH)
  gen-skin       Regenerate the Winrust Base skin in assets/skin
";

fn main() -> ExitCode {
    let task = std::env::args().nth(1);
    let result = match task.as_deref() {
        None | Some("help") | Some("--help") | Some("-h") => {
            print!("{HELP}");
            Ok(())
        }
        Some("gen-fixtures") => gen_fixtures(),
        Some("gen-skin") => gen_skin(),
        Some(other) => Err(format!("unknown task: {other}\n\n{HELP}")),
    };
    match result {
        Ok(()) => ExitCode::SUCCESS,
        Err(msg) => {
            eprintln!("{msg}");
            ExitCode::FAILURE
        }
    }
}

/// One-second 440 Hz stereo tones in every supported format, plus a two-second tone split
/// into two MP3 halves for the gapless test. lavfi's sine is phase-continuous, so the halves
/// join seamlessly when the decoder trims encoder delay and padding correctly.
fn gen_fixtures() -> Result<(), String> {
    let out = workspace_root().join("crates/audio/tests/fixtures");
    std::fs::create_dir_all(&out).map_err(|e| format!("create {}: {e}", out.display()))?;
    let tone = "sine=frequency=440:sample_rate=44100:duration=1";
    let formats: [(&str, &[&str]); 5] = [
        ("tone.mp3", &["-c:a", "libmp3lame", "-b:a", "128k"]),
        ("tone.flac", &["-c:a", "flac"]),
        ("tone.ogg", &["-c:a", "libvorbis", "-q:a", "4"]),
        ("tone.m4a", &["-c:a", "aac", "-b:a", "128k"]),
        ("tone-alac.m4a", &["-c:a", "alac"]),
    ];
    for (name, codec) in formats {
        ffmpeg(
            &["-f", "lavfi", "-i", tone, "-ac", "2"],
            codec,
            &out.join(name),
        )?;
    }
    let long = "sine=frequency=440:sample_rate=44100:duration=2";
    let halves = [
        ("half1.mp3", "atrim=0:1"),
        ("half2.mp3", "atrim=1:2,asetpts=PTS-STARTPTS"),
    ];
    for (name, trim) in halves {
        ffmpeg(
            &["-f", "lavfi", "-i", long, "-ac", "2", "-af", trim],
            &["-c:a", "libmp3lame", "-b:a", "128k"],
            &out.join(name),
        )?;
    }
    println!("fixtures written to {}", out.display());
    Ok(())
}

/// Draws Winrust Base and writes it to `assets/skin/` (committed; see spec §7.6).
fn gen_skin() -> Result<(), String> {
    let out = workspace_root().join("assets/skin");
    let count =
        xtask::gen_skin::write(&out).map_err(|e| format!("write {}: {e}", out.display()))?;
    println!("{count} skin files written to {}", out.display());
    Ok(())
}

fn ffmpeg(input: &[&str], codec: &[&str], dest: &Path) -> Result<(), String> {
    let status = Command::new("ffmpeg")
        .args(["-hide_banner", "-loglevel", "error", "-y"])
        .args(input)
        .args(codec)
        .args(["-map_metadata", "-1"])
        .arg(dest)
        .status()
        .map_err(|e| format!("cannot run ffmpeg (is it on PATH?): {e}"))?;
    if status.success() {
        Ok(())
    } else {
        Err(format!("ffmpeg failed for {}", dest.display()))
    }
}

//! Winrust Base, the built-in skin. Generated by `cargo xtask gen-skin` into `assets/skin/`
//! and embedded here; it fills in for anything a loaded skin lacks.

use crate::ini::decode_text;
use crate::skin::Skin;
use crate::sprites::Sheet;
use crate::{bmp, pledit, viscolor};

macro_rules! asset {
    ($name:literal) => {
        include_bytes!(concat!("../../../assets/skin/", $name))
    };
}

fn bitmap(sheet: Sheet) -> &'static [u8] {
    match sheet {
        Sheet::Main => asset!("main.bmp"),
        Sheet::Cbuttons => asset!("cbuttons.bmp"),
        Sheet::Titlebar => asset!("titlebar.bmp"),
        Sheet::Numbers => asset!("numbers.bmp"),
        Sheet::NumsEx => asset!("nums_ex.bmp"),
        Sheet::Text => asset!("text.bmp"),
        Sheet::Posbar => asset!("posbar.bmp"),
        Sheet::Volume => asset!("volume.bmp"),
        Sheet::Balance => asset!("balance.bmp"),
        Sheet::Monoster => asset!("monoster.bmp"),
        Sheet::Playpaus => asset!("playpaus.bmp"),
        Sheet::Shufrep => asset!("shufrep.bmp"),
        Sheet::Eqmain => asset!("eqmain.bmp"),
        Sheet::EqEx => asset!("eq_ex.bmp"),
        Sheet::Pledit => asset!("pledit.bmp"),
    }
}

/// Built with [`Skin::complete`], never the loader: loading falls back to this skin.
pub(crate) fn winrust_base() -> Skin {
    let sheets = Sheet::ALL
        .iter()
        .map(|&sheet| {
            let (w, h) = sheet.size();
            bmp::decode(bitmap(sheet))
                .expect("Winrust Base bitmaps are valid (checked by tests)")
                .fitted(w, h)
        })
        .collect();
    let mut skin = Skin::complete(sheets);
    skin.playlist = pledit::parse(&decode_text(asset!("pledit.txt")));
    skin.vis_colors = viscolor::parse(&decode_text(asset!("viscolor.txt")));
    skin
}
